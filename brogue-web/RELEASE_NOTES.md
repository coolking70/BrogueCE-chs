# Brogue 网页版 v0.2.0 — 交互层与内容完整性版本说明

发布日期：2026-09-29
基于 v0.1.0（规则层对齐）之后，经用户试玩反馈发起的两轮系统勘察与修复：**X-3 交互与自动行动层**（47 条差异）、**X-4 内容完整性**（26 条差异）全部处理完毕；另含前端响应式/触屏改版（FE-1）。

## 一、本版主要变化

### 交互与自动行动（X-3，对照 CE `executeKeystroke`、`rogue.disturbed`、`message/flavorMessage`、`confirm`）

| 方面 | 变化 |
|---|---|
| 自动探索/旅行 | 每步按玩家已知信息重算（CE `explore`/`travelRoute`），不再"此路不通"；遇敌连续攻击带 CE 保命刹车（HP ≤ 预期伤害即停）；受击、受伤、地形/状态效果、任何消息、任意按键均打断；普通物品与盟友不打断，钥匙/楼梯/传送门/锁门首见即停 |
| 按键 | `x` 自动探索（检视改长按/右键）；`>`/`<` 前往已发现楼梯；`Z` 长休息（需恢复时最多 300 回合）、Ctrl-S 连搜、Shift/Ctrl+方向奔跑、小键盘；`.` 纯休息；`e/r/d/c` 背包预选；`R` 重标与题字 |
| 防呆与确认 | 已知岩浆拒绝进入；火焰/危险气体/压力板/酸性怪攻击前确认；撞盟友换位、撞俘虏确认释放；诅咒装备不能卸下/丢弃/被替换；投掷已装备或已附魔单件前确认；自动行进遇确认先停步 |
| 消息 | 地形描述走位置描述行、不再刷日志；CE 需确认级消息醒目确认；漂浮/免火危险地形返岸预警；同回合折叠；状态到期/饥饿/拾取文案对齐 CE；战斗文字按 CE（分级动词、回合末合并、远处战斗提示），**显示设置中保留默认关闭的"显示伤害数值"开关** |
| 其它 | 麻痹期间自动连续推进；删除自创"幻觉随机踉跄"；侧栏按 CE 列出物品/地形、怪物状态标签、力量/护甲/金币/潜行范围；装备力量不足提示、满包提示、丢弃/投掷物品不被自动探索回捡 |

### 内容完整性（X-4，对照 CE 目录与 2000 层生成普查）

| 方面 | 变化 |
|---|---|
| 世界目录 | 血根草茎/荚与治疗孢子（踩爆/燃烧释放，回血按 CE 公式）；干草/尿液/杂物/烧焦地毯恢复为独立实体（原被替身）；9 种物种血迹、周期/激活 DF、燃烧飞镖 DF |
| 生成 | 藻井与藻水可生成（0→258/2000 层）；D26 强制护符房（Warden、开关）；营地随怪群生成（0→279）；CE19 燃烧飞镖/焚化药水二选一；CE9/10 按有效特征数 |
| 物品与生物 | 燃烧飞镖投掷爆燃；补"激怒怪物"卷轴；物种按伤害流出对应血迹；娜迦水迹、火蜥蜴火迹等周期留痕 |
| 物品详情 | 按 CE `itemDetails` 移植：未知外观描述、已知说明、装备/符文/法杖/魔杖数值与再附魔预测、戒指/护符、食物、诅咒与探测、来源层与法杖使用记录 |
| 文字 | 215 种地形 CE 描述与 188 条风味文字中文目录接入检视/侧栏/位置描述（89 个误显"地面"的地形已修正）；怪物专属召唤句与吸收状态词 |

### 前端（FE-1）
响应式布局（桌面/平板/手机竖横屏）、触屏命令栏与虚拟方向键、点击/长按/拖动/捏合手势、目标选择确认条、视觉统一；植被等字形强制文本呈现（不再显示为彩色 emoji）。

## 二、已知差异与明确不做

- 不追求同种子逐骰一致（规则一致、地图合理即可）；不兼容 CE `.broguerec`；不做旧存档迁移；不做无障碍。
- web 自创内容只保留定义；装饰性随机流独立于游戏随机数；不复制 CE 未定义行为。
- 冰、旧法杖洞、调试 DF、CE 停用蓝图 48、仅 Bullet 变体的 CE72 按有效范围不激活（见 `ai_docs/reports/x4-r1-evidence/catalog-ledger.md`）。

## 三、验证方式

- 两轮勘察（`ai_docs/reports/x-3-survey.report.md`、`x-4-survey.report.md`）逐条给出 CE 与 web 出处；每个修复单元附报告、单变量反事实与重录登记。
- 分档门禁：纯前端轻档、引擎非规则中档、规则/生成/RNG/存档全量；发版前全量兜底。
- 约 240 个测试文件、4500 项断言；生成基线（D1–D26、D27–D40）与三份黄金 trace。

## 四、构建与运行

```bash
cd brogue-web
npm ci
npm run build        # 产物在 dist/
npm run dev          # 本地开发服务器
npm test             # 全量测试（约 30 分钟）
npm run test:drift   # 生成回归基线
```

## 五、在线试玩

测试构建以 Claude Artifact 形式发布（与 GitHub Pages 上的旧 C/WASM 版互不影响）。

# 附：v0.1.0 — 阶段性版本说明

发布日期：2026-09-27
代码基准：Brogue CE（本仓库 `BrogueCE-master/`）；Web 实现：TypeScript + Vue 3（`brogue-web/`）

本版本是第一个"规则层面与 Brogue CE 对齐"的阶段性成品：地牢生成、怪物 AI、战斗、物品与魔法、机关、终局、存档与录像均按 CE 源码实现，并以 CE 原函数编译对照、真实玩家命令端到端验证和约 4000 项自动测试守护。

## 二、已知差异与明确不做

- **不追求同种子逐骰一致**：规则与 CE 一致、地图合理（可达、可通关），但同一种子不保证生成与 CE 完全相同的地图（项目裁决）。
- **不兼容 CE 二进制录像（`.broguerec`）**；录像为 web 命令日志 JSON（v2），旧版本录像直接拒绝。
- **不做旧存档迁移**：开发阶段存档格式变化时旧档不兜底。
- **web 自创内容只保留定义**：11 个自创蓝图、自创物品/符文不进入正常生成，也不在公开 test 模式出现。
- **光照随机色使用独立装饰性随机流**，不影响游戏随机数，也不与 CE 逐值相同。
- 不复制 CE 的未定义行为（如无合法落点时的越界访问），改为有限失败策略。

剩余的非阻塞细节（部分 AI/寻路/谱影的逐项比对、自然长局深层录像等）见 `ai_docs/reports/x-2-survey.report.md` §7。

## 三、验证方式

- **CE 原函数对照**：多数规则单元提取 CE C 源码原文编译为 oracle，与 web 实现逐组合比对（如状态机 10240 组、护符曲线 624 值、选点候选 256 组）。
- **真实命令端到端**：机关、偷窃、复活、超胜利等以真实玩家命令从入口操作到结果，并在浏览器中实测。
- **自动测试**：约 220 个测试文件、4000 项断言；生成回归基线（D1–D26 与 D27–D40 各一份）与三份重构黄金 trace。
- **勘察复核**：X-0（全项目）、X-1（收尾）、X-1b（深层）、X-2（终期）四次只读勘察，结论与证据见 `ai_docs/reports/`。
