# U21c：地形外观、动画清帧与 flare

依据：任务书 §0 指定的 X-0 §4.4 U21、§3.1 K16；CE 以本工作树 `BrogueCE-master` 为准。未改生成流程、生成基线或 Git 暂存区，也未提交。

## 实施

1. `TerrainAppearanceCatalog.ts` 为当前 **137 个** `TerrainType` 逐项登记 CE `Globals.c:315-579` 的字形、前景与背景基础色。`Appearance.ts` 按 `IO.c:1160-1188` 分别选择四层中的字形、前景与背景优先级，跳过气层的直接字形；五种随深度变化的背景色按 `RogueMain.c:537-544` 插值。`Record<TerrainType,...>` 是编译期覆盖守卫，未知枚举运行时抛错；新增测试逐枚举检查并钉住力场、晶墙、藤蔓、碎石。web 专属别名映射到对应 CE tile（例如 `WATER_SHALLOW→SHALLOW_WATER`、`ALTAR→ALTAR_INERT`）；CE 为 0 的透明字形/前景从底层继承。CE 的随机颜色舞动仍沿现有确定性渲染口径，不从玩法 RNG 取数。
2. `Game.tickBoltAnimation()` 在最后一帧到期时返回一次需要重绘；`GameCanvas` 随即隐藏 projectile sprite。定位到原代码清空 `pendingBoltFrames` 后返回 `false`，ticker 因此不调用 `render()`；这是末帧可能残留的执行路径。历史自然施法残留未在本轮重现，浏览器用合成射线帧做了前／中／后反事实验收。
3. 依 `Light.c:291-403` 新增 flare 系数、每 10ms 衰减、半径与颜色同比缩小、失效时清帧。通过 `LightMap.paintLight` 的临时光网格绘制，和基础玩法光网格分离；动画结束后显示光恢复原值。已接入卷轴附魔、保护武器／护甲、力量药水和 empowerment 命中。后者删除 W-21 的 180ms 怪物字形闪光，按 `Items.c:5316` 使用半径 6 的 `EMPOWERMENT_LIGHT`。开新局、换层和读档会丢弃旧 flare。
4. 侧栏按 U21a `canSeeMonster` 列怪物身份、HP 比例和有名称的状态，隐藏隐形／休眠／死亡且未揭示的怪物；与地图和 `render_game_to_text` 使用同一身份谓词。390px 视口将侧栏置于地图下方，并把触控控制放回地图区域。

## 边界

CE 对动态色还有色彩随机抖动，本轮保持 web 既有“不消耗玩法 RNG”的口径；地形基础色及深度插值已对齐。flare 临时光只参与画面合成，不改变玩法 FOV 或地图知识；CE 在 flare 帧中调用 `demoteVisibility/updateFieldOfViewDisplay` 的短暂揭示效果尚未完整移植。390px 截图仍显示整张 79×47 地图等比缩放，已探索区域因此较小；本轮未改变相机或生成流。

## 验收裁决后的测试对齐

依据任务书裁决与 X-0 §4.4 U21、§3.1 K16/K17，对 U21c 造成的旧测试冲突逐类处理；未改生成基线。

1. `scripts/u21c-ce-appearance.mjs` 从当前 CE `Globals.c` 的 `tileCatalog` 和颜色常量、`GlobalsBase.c` 的基础颜色、`platformdependent.c` 与 `platform.h` 的字形映射，独立生成 `src/test/fixtures/u21c-ce-terrain.json`。137 条按 web 枚举名索引，每条保留 `ceTile`、`ceLine` 和解析得到的 `{char,color,bgColor}`；仅 web 专属名称使用脚本中的显式 CE 别名。脚本只从 `Grid.ts` 读取枚举名称，不读取 `Appearance.ts`、`TerrainAppearanceCatalog.ts` 或其运行输出。运行 `node scripts/u21c-ce-appearance.mjs --check` 可对照 CE 源重新计算并检查表未过期，实测 137 条通过。R-1 穷举可见态和记忆态继续逐成员全等断言；旧 web 自编 `DEFAULT_LOOK` 表已撤换。CE 动态色按深度 1、`AMULET_LEVEL=26` 的整数插值产生期望。
2. R-1 与 UI-1 的 FLOOR/浅水样本使用 CE 解析表给出的基础字形、前景和底色；无光、记忆、气体零密度与幻觉未命中分支仍逐字段核对。测试本地 `lightColor/lightBg` 按 CE 公式独立计算预期：逐通道 `base × adjusted / 100`、超过 150 时平方根压回、负通道钳 0、255 饱和，前景和背景分别核对。光照输入和公式断言没有放宽；只是移除了旧 `#aaaaaa/0x222233` 等样本常量。三文件定向复跑 106/106 通过。
3. `bgColor: null` 在渲染消费端表示透明背景：`GameCanvas.vue` 仅在 `!== null` 时填充和登记背景；`Appearance.ts` 的分层继承、光照、记忆分支也以此为门。数值 `0` 则是 CE 明确给出的黑色背景，会被填充。保留这一种语义区分，未把 null 与 0 互换；黄金表中的 CE 零背景指针仍是 null，`&black` 则为数值 0。
4. W-21 的旧 180ms 字形闪光是临时表现。命中测试现断言不存在该帧，并按 CE `Items.c:5316` 检查 `EMPOWERMENT_LIGHT` flare 的初始记录；免疫、反射、空射、不可观察接收者均不得制造闪光。`Game.ts` 在 `canObserveBoltTarget` 成立后才创建可见 flare，隐藏怪物能力仍生效但不泄漏位置；可见、心灵感应、着迷及可观察盟友各自受测。U21c 独立测试还覆盖半径 6、衰减清帧及射线末帧重绘。
