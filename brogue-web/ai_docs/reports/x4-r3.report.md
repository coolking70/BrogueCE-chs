## 2. 状态与 U03 保存契约

`bloodType`／`DFChance`／`DFType` 为物种信息的派生 getter，不是新增实例 own field；没有新增 DF 计时器。目录字段不参与随机生成选择，不改变行动速度。依赖当前存档中已存在的 `typeId`、`mutation`、`deathDFType` 及行为旗标；地图结果沿现有 `layers`／`volume` 保存。新增卷轴沿既有物品 `consumableId`、种类知识、外观表和计量数组保存。不迁移旧档。

变异、消魔和复活的信息重置需要与 CE 区分：爆裂／寄生变异把 DFChance 改为 0；消魔可以清掉变异身份，但 CE 不恢复 info；复活召唤者则恢复目录 info。`Monster.mutate` 把两种变异 DF 写入**已经登记并保存的** `deathDFType`；这两个 DF 身份均隐含 chance=0。即使真实消魔清掉 `mutation`，覆盖仍存活并随原图编解码往返；变形删除覆盖，复活召唤者写回目录值。没有新增序列化字段。完整分类见 [state-contract.json](x4-r3-evidence/state-contract.json)；专项守卫包含真实消魔、JSON 图往返零 RNG、复活后不重套旧变异 DF。
