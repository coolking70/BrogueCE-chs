## 1. CE 依据与落地

| CE 源码 | 规则 | web 实现 |
|---|---|---|
| `Movement.c:1173-1189,1193-1215,1218-1219` | 鞭/矛优先；俘虏在普通攻击前确认释放；非 discordant 盟友跳过攻击 | `Game.performPlayerAction` 保留几何攻击先行，分出 captive / hostile-or-discordant / movement 三条路径 |
| `Movement.c:1440-1461` | 玩家先移动，盟友先放到玩家原格，然后 `monsterAvoids`；避免时在玩家新格附近搜索 | `movePlayerPastAlly` 复用现有 `monsterBlinkAvoids`（与怪物行走共用的 CE 避险查询），所有普通移动/空祭坛落位同步处理盟友 |
| `Movement.c:1451-1454`；`Monsters.c:650-670`；`Grid.c:287-360` | `getQualifyingPathLocNear(player.loc,true,forbiddenFlagsForMonster,0,0,HAS_PLAYER\|HAS_MONSTER\|HAS_STAIRS,false)` | `CreaturePlacement.allySwapCandidates` 调用既有 `qualifyingPathCandidates`；路径受物种永久旗标限制，终点排除玩家、其他活跃怪及楼梯；最近路径同距格用 substantive RNG 均匀选取，无路径时沿用方环回退 |
| `Movement.c:812-852` | 先酸性确认，再首个可见 discordant 盟友确认；混乱或无心灵感应的幻觉豁免 | `abortPlayerAttack` 包装 U1 酸性检查；普通近战、横扫、鞭、矛及移动攻击共用入口，在伤害/恶心掷骰前收齐问题 |
| `Movement.c:1193-1215,616-656,728-755` | `Free the captive X?`；有匹配钥匙则提升格层，再 `freeCaptive`；`ticksUntilTurn += attackSpeed`；拒绝无回合；混乱已 committed 时不再提问 | 复用钥匙匹配/一次性语义、地形提升事务和既有 `freeCaptive`。直接收 attackSpeed，玩家不移位，不调用武器攻击恢复、恶心或 entrancement 移动 |

CE 的换位顺序有一个容易误修的细节：`monsterAvoids` 查询时盟友已经位于玩家原格，深水等“当前已处于该地形”的例外仍然成立。这里按原文保留并加守卫，没有额外扩大避险条件。临时漂浮可允许盟友直接接替岩浆原格；一旦进入搜索，搜索限制来自永久物种旗标，和 CE 一致。

复用的路径函数在病态地图无任何合法落点时返回空集合；CE 此时返回 `INVALID_POS`，后续坐标没有安全定义。web 在这一分支恢复双方原位置，避免越界或重叠。正常换位和 CE 两级回退规则不受影响。

英文默认问题与中文资源分别为 `Are you sure you want to attack {{monster}}?` / `你确定要攻击{{monster}}吗？`、`Free the captive {{monster}}?` / `释放被俘的{{monster}}吗？`。沿用 `requestConfirm`：自动行进在提问前停止，录像读 `commandDecisions` 而不打开 UI。
