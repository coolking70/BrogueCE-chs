## 3. 时长、反射、攻击解除

- `PowerTables.c:56` 原函数是 `((int)(enchant * 3 / FP_FACTOR))`。`Items.c:5352` 传 `magnitude * FP_FACTOR`，玩家杖由 W-5 的实例附魔解析，所以整数 E 得到 **3E**。重新施法直接覆盖，可把长时长缩短；不是 max、叠加或读取 charges。
- `scripts/w18-ce-golden.mjs` 提取未改的 CE 原函数，用 clang 编译；黄金值包含 E=0..50 和 6 个固定点边界，共 57 行。E2/3/8 分别 6/9/24；正式游戏实例量纲沿 W-5。
- `Items.c:5342-5364`：实际命中玩家赋 **confused**，不是 entranced；命中怪物排 INANIMATE/INVULNERABLE，写 entranced 后 wakeUp。按施加后的可观察性判断 autoID；`Monsters.c:165-175` 的 entrancement 本身会透露位置，所以不可见目标也可在受术后被察觉。
- 真实反射弹道仍走 W-3/W-4。必中反射回玩家、随机反射击中旁观者均测试；反射者本身不受术。玩家混乱移动按 `Movement.c:1097-1138` / `674-699` 在物理合法方向中抽选，跟随者再取 **实际抽到方向** 的反向；不是继续跟随原按键。等待不随机走动。此修正适用于其它来源的玩家 confused；原 hallucinating 扩展保留。
- 近战解除位于 `Combat.c:1183`，早于命中掷骰；投掷武器位于 `Items.c:6790`。因此 miss、抓取尝试也解除。`Combat.c:1159-1162` 自爆早退和 `1173-1177` 水生对悬浮目标的拒绝早退发生在解除之前，均有守卫。
- 伤害射线走 `Items.c:5210-5213 → Combat.c:346-359 moralAttack`；玩家起源、已经反射的伤害射线跳过该段，真实反射火命中旁观者的测试确认 **HP 下降但仍反向跟随**。火免目标不解除，护盾吸收不免除有效攻击的解除。
- 不把解除塞进 takeDamage：普通环境伤害、毒伤、坠落伤害并不等价于攻击；环境/毒持续掉血时仍能保持催眠。坠落幸存者由独立跨层分支解除。

## 4. P2 调度与 W-9 入口

方向动作先同步驱动 moveEntrancedMonsters，成功步行设置 monster.movementSpeed 的预算，受控攻击设置 attackSpeed；撞墙失败不重设旧预算。此时 **不检查 ticksUntilTurn 是否到期**，所以快慢怪都是每个合格玩家方向动作一次。

随后才进入 P2 advancementLoop。`Time.c:2727-2731` 的调度跳过条件已加入；Monster.takeTurn 本身也防御早退，禁止自主走、打、施法、召唤。到期预算按 movementSpeed 续上。持续时间沿现有 100 tick 客观块递减，玩家 haste 下两次方向动作可以只衰减一次，slowed 下只跟一步但衰减两次；期限在客观块归零后可以恢复当次正常 AI。未改变 objectiveTimeBlock、playerTurnEnded、速度公式和环境周期。

**ENTRANCEMENT 走 applyBasicBoltEffect。** 与 W-9 同为按真实命中者、living 资格、CE magnitude 直接写状态/处理 autoID 的定向效果，没有毒浓度等额外算术载体。其后续动作消费明确放在移动/战斗/调度入口，而不是施法函数伪造一次动画。现有 MONSTER_BOLT_TABLE 没有原生 entrancement 消费者，不为未来 W-22 学习或 W-25 入池添伪目录项。

## 5. W-11 安置、陷阱、深水、熔岩、C-5

- 受控移动用 placeCreature 提交，保留占位检查、瞬时环境、视野刷新。新增可选 walkingSecretDoor，仅受控步行使用；普通 teleport/blink 默认策略不变。先通过整步合法性检查，再对可见密门执行发现；不因一次失败提交开启密门。
- 真实毒气压力板会向 GAS 层发出 POISON_GAS 并增加 volume；不能误把“暗陷阱本体消失”当作唯一触发证据。
- 深水可进入、不会淹死，继续沿 P1-27 的 CE 深水策略。熔岩立即造成真实死亡并进入既有死亡清理；飞行/悬浮、火免相应豁免，均有实体断言。
- 深渊落格先标 falling；紧接的 playerTurnEnded 顶部就会调用 monstersFall，不能强行等下一 100 tick。C-5 6–12 的伤害/护盾/幸存者转入下一层队列均复用；幸存者按 `Time.c:1564-1566` 清 entranced、seized、seizing，实际只转移/受伤一次。

## 6. 共用入口行为变化明列

1. Monster.takeTurn / Game.advancementLoop：仅 entranced 者新增自主行动禁止；状态到期或攻击解除后恢复原 AI。
2. Monster.willAttackTarget 及盟友选敌：接 CE 催眠优先级；受控怪可打非盟友的同类/俘虏；普通敌对兜底依旧可以打玩家/盟友；盟友避开受控者，P4-6 多目标攻击共用同一资格。普通 confused 攻击者的几何资格也按 CE 可伤同阵营（俘虏等前置门仍保留），并非只修改受控攻击者。
3. 怪物伤害 bolt 选敌避免攻击 entranced 敌人；非盟友消魔者可解救自身阵营受控者，排除会因消魔死亡的同类。完整 negation 资格仍属 W-23。
4. findLiveSeizer 不再把受催眠抓取者当作能继续 抓住玩家的对象；受控怪自己的 seized 仍按相邻敌对 seizer 判断，空格移动放开自己的 seizing。抓取/挣扎保留原 P4 已提交动作口径。
5. Combat.attack 与 resolveThrownWeapon 接尝试解除；水生物理攻击悬浮/飞行目标在解除前拒绝，BE_DAMAGE 旧公式调用不受这个物理门影响。怪物伤害 bolt 的既有非 CE 命中/伤害公式未顺带重写。
6. 玩家 confused 从“只有状态”补为真实随机方向；所有来源共用，自动行进也转回同一动作入口。普通玩家撞墙/无钥匙失败不再由渲染脏位错误推进时间。
7. 可观察性、渲染和文本状态输出承认识别 entranced 目标，但验收以位置/HP/时间为准。
8. wakeUp 会警觉队友、重设目标预算；未引入运行期以外的生成调用或抽签。
