CE 这些分支直接写状态，不查询 web 的自创 `statusImmunities/statusResistTurns`。本轮定向入口按 CE 资格判断并用 `setStatusDuration` 写入；泛用入口保留不动。现有 `monsters.json` 没有这五种状态的 immunity/resist 数据项，但新增合成用例明确证明此边界，避免将来混用。速度修改后调用原 `refreshSpeeds`；状态到期由未修改的 `tickStatuses` 恢复基础速度。

## 2. 三项旧行为与 hits 契约

`applyBoltResult` 继续逐格执行 W-4 的真实轨迹：每次 `onCell(pos,hit)` 用当前 **hit.creature** 创建 contact，交给 `applyBoltEffect`。后者从 contact 的 `hits` 取对象，不重新查怪物坐标，不以 caster 身份代替对象，也不把 `reflections` 当命中。未命中时仍允许其它落点效果执行，但五种定向效果在 `!target` 处退出，autoID=false。

- **heal/haste 自施退役**：只治疗/加速 hit 中的实际接触者。治疗飘字随该目标坐标，治疗/加速中英文消息包含实际目标；玩家仅在被射线实际命中时获得效果。
- **空射自隐形退役**：删除 miss→this.player 回落。空地、墙挡、射向旁边、原点拒绝、反射后飞入空地，都不会给玩家状态。
- **discord 错配退役**：使用 discordant；已有 `monstersAreEnemies`/怪物内讧消费者收到正确状态。玩家和怪物都可成为实际接触者；AI 不选玩家施放 discord 与射线实际命中玩家是不同判定。

新增五效果参数矩阵证明：直击仅目标变化；石像卫士原路反射后 `hits=[player]`，玩家获得正确效果而反射者不变；golem 随机旁射空地 `hits=[]` 不自施；旁射友军 `hits=[bystander]` 只影响旁观者，不按阵营改对象。测试不伪造 hits 来替代实际 tracing。discord 效果测试借现有 `CEBoltType.DISCORD` 构造配置，不新增生产物品。

真实 P2 提交另验 haste：普通命中消耗玩家100 tick；反射命中玩家后按加速速度消耗50 tick，均只扣1充能。显示时长可能已被客观回合递减，数值断言在命中时捕获，回合消费另验。
