## R3 / R5 / R6 接口交接

1. **治疗（R6，必接）**：`terrainHealingAmount(cell, currentHP, maxHP, ticks, inanimate, submerged)` 返回本次增量，无RNG、无副作用。按 `Time.c:645–657` 两次C整数除法：`max(1, floor(floor(maxHP/15)*ticks/100))`，再截到缺失HP；排除无生命/潜水，满血返回0。应在 `Game.applyEnvironmentalEffects` 的渐进暴露分支（现有伤害处理邻近处）对存活生物调用，不能放进瞬时入格回调造成重复治疗；玩家确实回血时才输出 `worldHealingText()`。漂浮、火免疫、呼吸护甲不是CE治疗豁免条件。当前Game没有该调用，报告明确保留此集成缺口。
2. **受击血迹（R3/R6）**：物种 `bloodType` 对接 DF23–31，复用已有DF32腐气。`Combat.c:1827–1837` 要复制目录条目后按伤害调整 startProbability，不能修改共享目录：`floor(start * (15 + floor(min(damage,currentHP)*3/2)) / 100)`；GAS再乘100，使用伤害前当前HP，damage>0才执行。旧60%红血helper应在集成时替换。
3. **周期/激活（R3/R6）**：物种录入 `DFChance/DFType`。娜迦100%→48，火蜥蜴100%→45，幻影2%→50，火舞者100%→37，独角兽1%→47；守卫/有翼守卫/镜像图腾为92/91/93。普通周期按 `Time.c:2685` 在客观更新中执行，排除 `MONST_GETS_TURN_ON_ACTIVATION`；激活行动按 `Monsters.c:3341` 在monster turn的瞬时地形/麻痹提前返回之前执行，不得两个入口重复。目录层供给已完成。
