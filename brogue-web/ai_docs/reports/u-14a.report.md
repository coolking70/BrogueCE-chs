# U14a：状态缺口第一轮

依据：本工作树 BrogueCE-master；X-0 §4.1、§4.3 U14、§3.1 K14/K25，范围按任务书 §1 收窄。实现虚弱层数、恶心和魔法恐惧的现有消费者；黑暗仅状态载体。未扩生成池、未修改矿灯/FOV/潜行公式、未做旧档兼容。使用 develop-web-game 技能验证浏览器。

## 1. 结论与范围

- 新增 `weaknessAmount` 和本轮四项的 `maxStatus` 子集；`StatusId` 加 `nauseous/darkness/magical_fear`。不改独立 nutrition/searchingCharge，不添加 U14b 状态。
- 怪物虚弱进入伤害、精度、防御三公式；玩家通过 `effectiveStrength = strength - weaknessAmount` 即时消费装备、护甲符文、反射、投掷射程和详情，无需维护第二份装备缓存。
- 恶心接现有臭烟地形；物理行动有25%概率呕吐、铺 `DF_VOMIT`、消耗移动时间，没有额外伤害或营养罚款。
- **当前 CE 没有活跃的魔法恐惧施加来源**：`Items.c:4798–4827 causeFear` 整段注释，全src搜索未发现其他正持续期施加路径。内部状态施加/刷新供合成验证；不创造恐惧卷轴、怪物能力或从普通FLEEING自动上恐惧。
- **黑暗药水目录仍不存在**，POTION_DARKNESS映射仍为null。提供状态载体，不伪称玩家已能自然喝到黑暗药水；光照消费者留U21b。
