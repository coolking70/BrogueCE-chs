# U06：怪物直接法伤

以本地 X-0 §4.1、§4.3 U06、§3.1 K09 为准，基准 HEAD `364cc10`（含 U01）。**FIRE / SPARK / DRAGONFIRE 已移出近战判定，直接复用 W-8 `rollStaffDamage`，以既有 CE 目录 magnitude 掷伤害。** 命中不再受施法者 accuracy/damage、目标护甲及近战附带能力影响。BE_ATTACK 保持原执行代码；未改怪物施法选择、bolt 目录、生成代码或存档。

## 1. CE 权威执行路径与本轮边界

本轮逐段读取工作树 `BrogueCE-master`，没有沿用任务书的旧 Combat 行号。主要依据：`src/variants/GlobalsBrogue.c:58–90`、`src/brogue/Items.c:5130–5219`、`PowerTables.c:49–51`、`Math.c:40–59`、`Combat.c:346–382 / 1800–1930`、`Monsters.c:2764–2783`。CE 文件未修改。

`Items.c` 的完整 BE_DAMAGE case 顺序如下：

1. 进入实际承伤生物（此前排除 submerged、完成反射）后，`autoID=true`，即使免疫也成立。
2. 玩家施法先处理 paladin feat；此为玩家专用成就，本轮怪物入口不适用。
3. BF_FIERY + `STATUS_IMMUNE_TO_FIRE`，或 `MONST_INVULNERABLE`，进入免疫分支。可见时打印忽略该法术的消息；**免疫检查在伤害掷骰前**。武器免疫不属于此门。
4. 否则 `staffDamage(theBolt->magnitude * FP_FACTOR)` → `inflictDamage(caster, monst, damage, backColor, false)`。`false` 表示先走护盾。没有 `attackHit`，不读取 accuracy、damage range、defense，不执行攻击符文/毒/虚弱/抓取/自爆等近战效果。
5. 致死分支：若玩家 HP≤0，`killCreature`，仅当 `caster == &player` 才设置 `Killed by a reflected ...`，然后立即终止 bolt、跳过本格火暴露。其余死亡按可见性/无生命分别打印 kills/destroys 或听到死亡，调用 `killCreature`。
6. 存活分支：符合条件的非盟友/非永久逃跑者转 TRACKING_SCENT、清 magical fear；可见射线打印命中；火系先 `exposeCreatureToFire`。若未反射或 caster 不是玩家，执行 `moralAttack`、`splitMonster`。因此**怪物来源的反射伤害仍会解除控制、分裂**，即使伤害被盾全吸收。
7. 除玩家致死的提前返回外，火系最后 `exposeTileToFire`；后面通用 updateBolt 路径还处理 DF/火/电地形。web 沿用 W-3 的逐格地形出口，不新增第二次点火。

`inflictDamage` 还包含：零伤害/无敌门、十倍单位护盾吸收、停止吸收尸体、血迹 DF、唤醒、easy 模式减伤、盾后的 transference（上限为目标当前 HP，盟友40%/敌人90%，不封顶 maxHP）、扣血/濒死逃跑/闪光/侧栏。`moralAttack` 还包括解除麻痹并给反应 tick、fear 递减、解除入迷、ENRAGED、玩家攻击盟友解除盟友、告警。这些完整系统并非现有 web `takeDamage` 的等价物，不能把本轮叫作完整移植 `inflictDamage`，未覆盖部分见 §8。

本轮接通已有载体：盾 → transference → `takeDamage(..., true)`；存活火暴露 → 解除麻痹（`min(caster.attackSpeed,100)-1`）/入迷 → 分裂；已有非盟友且非 FLEEING 状态转 HUNTING。死亡继续由 `finishTurnEpilogue` 的 `triggerDeathFeatures` / `removeDeadMonsters` 及玩家 `triggerGameOver` 收口，不另加掉落或死亡 DF 所有者。

CE 范围函数是 `(2 + E) * 3 / 4` 整数截断、`4 + 5 * E / 2` 整数截断，clumps=`1 + E/3` 整数截断。现有目录 `monsterBoltMeta` 已从 `CE_BOLT_CATALOG` 带入正确值，**无需改表**。玩家 STAFF 的 E 来自实例附魔，怪物来自目录；不把表中的 magnitude 当固定 HP 伤害。

[编译脚本](../../scripts/u06-ce-golden.mjs) 从当前 CE 文件按函数边界提取 `staffDamageLow/High/staffDamage/randClumpedRange` 原文及 `fixpt/FP_BASE/FP_FACTOR`，用 clang 编译。仅以可枚举的 `rand_range` 替身返回合法骰面，穷举全部组合；这是分布/舍入/调用区间证据，不是 CE 与 web 全游戏 PRNG 同种子比较。

- [抽取的 C](u-06-evidence/ce-staff-damage.c)、[编译输出](u-06-evidence/ce-staff-damage.txt)、[黄金分布 JSON](u-06-evidence/ce-staff-damage.json)。新测试通过 web 原语穷举同一空间，逐点比较整条概率权重；另外真实 `castMonsterBolt` 测伤害两端、stats 无关和 `randomNumbersGenerated`。

**BE_ATTACK 保留证明**：CE `Items.c:5136–5145` 的 DISTANCE_ATTACK、POISON_DART、WHIP 调用 `attack(caster,monst,false)`，不是 staffDamage。本轮只把前两种从混合分支留下，分支内部执行代码不变；[边界审计](u-06-evidence/boundary.json) 对 HEAD 与最终版本提取 POISON_DART 的实际 fallthrough 分支，去注释后 AST 打印逐字相等。新增测试锁住未命中、武器免疫、毒攻击骑乘效果与非 staff RNG；WHIP 仍通过 `Monster.performWhipAttack → resolveGeometryAttackOn → CombatSystem.attack`，没有向怪物 bolt 表新增 WHIP。P4-6/W4/W10 等旧守卫只回归。
