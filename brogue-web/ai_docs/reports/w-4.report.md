## 3. hits 最终语义（W-1 交接）

**执行完成的 `hits` 是沿实际轨迹、反射判定之后，进入效果分派的活体接触序列。**

1. 生物引用为真实接触者，可以是玩家、原 caster 或任意旁人；pos 是当时坐标快照，移动后不会跟着变。
2. 成功反射的对象不进 hits，单独进 `reflections`（折点、pathIndex、生物或 terrain=null、朝 caster/随机）。同一对象往返接触多次就有多条 hits。
3. hits 表示被射线实际击中并尝试效果，**不保证扣血或效果成功**：物理 miss、无敌、状态免疫、未实现效果仍可能有接触。伤害损失不能由 hits.length×magnitude 推算。
4. path/frames 保留反射格和所有回程格；landingPos 是真实最后到达格，可能回到 origin；impactPos 的空路回落契约不变。
5. 纯预览 `outcome=null` 的 hits 是不掷反射骰的预测接触，不能当作结算。正式出口会整体替换成实际结果，outcome 总有已评估值。
6. **W-9/W-15 的旧自施增益例外仍明确存在**：玩家 HEALING/HASTE/SHIELDING 及空射 INVISIBILITY 的旧 effect-local self 路由不伪造成额外路径碰撞。hits 不声称列出这些历史自施旁效的所有受益者。W-0 已把它们的真正定向目标修正安排给对应效果轮，本轮不越界。

例如火打守卫：`path x=[5,6,7,8,7,6,5,4]`，reflections=[守卫]，hits=[玩家]，玩家100→94、守卫不掉血；旧“hits=守卫、直接给玩家减血”的限定已过期。
