## 2. `negationWillAffectMonster` 与 `negate` 逐项对照

**纠正任务线索的因果说法**：IC:6016 用前者决定已知消魔魔杖的自动候选；IC:5301–5307 的自动鉴定用的是 **`negate` 返回值且消魔后 canSeeMonster**，并不直接调用前者。二者不能合并，更不能用 HP/status JSON 差异代替实际返回。

| 条件/动作 | IC:4421 资格函数 | IC:4465 实际 negate | web |
|---|---|---|---|
| `MA_REFLECT_100` | isBolt=true 时直接 false；非射线不因此拒绝 | 本函数不防反射，先剥该 ability；反射由射线路径处理 | 相同；卷轴可消除镜面/守卫 |
| `MONST_INVULNERABLE` | 无条件 false | **不是顶层早退**；先剥 ability、清 SEIZING，再跳过存活普通分支 | 保留该不对称；没有用资格函数封锁接触 |
| abilityFlags 中非四种保留位 | true | 与保留掩码相与；affected=true、wasNegated=true | 遍历删除对应 Set 成员 |
| `MB_SEIZING` | true | 清自身 seizing、affected=true；不写 wasNegated，不直接清对方 seized | 相同；受害者后续原有抓取有效性校验解除 |
| `MONST_DIES_IF_NEGATED` | true | 在状态清除之前死亡、返回有效，不进下方状态/计数/地形分支 | 三文案，绕盾死亡；死亡前仍剥 MA_DF_ON_DEATH |

## 4. traits、abilities、bolts、突变

`NEGATABLE_TRAITS` 按 RH:2091–2092，九位：INVISIBLE、DEFEND_DEGRADE_WEAPON、IMMUNE_TO_WEAPONS、FLIES、FLITS、IMMUNE_TO_FIRE、REFLECT_50、FIERY、MAINTAINS_DISTANCE。其他行为位如免蛛网、不可移动、无生命、性别、逃跑倾向、携物、从不睡眠均保留。

`MA_NON_NEGATABLE_ABILITIES` 按 RH:2131，仅保留 ATTACKS_PENETRATE、ATTACKS_ALL_ADJACENT、ATTACKS_EXTEND、ATTACKS_STAGGER。其他 abilityFlags 全部移除，包括召唤、寄宿、抓取、毒击、虚弱、分裂、死亡DF、反射100等。剥离先于 die-if-negated，所以不能让纯魔法造物死后又从本轮已剥离的 MA_DF_ON_DEATH 产生爆炸/孢子。

突变按 GC:1396–1413：explosive、infested、grappling、vampiric、toxic、reflective 可消；agile、juggernaut 保留。CE 实际只清 mutationIndex，**不反算 maxHP/伤害/速度/防御等 info 数值**。web 清 mutation 标记及突变展示前缀/色，保留数值；不可消突变不变。现有 mutated info/缺省字段的正确保存由 snapshotForm 负责。mutations.json 原有倍率/旗标录入债项未改，生成抽样不变。

### bolt 两遍循环与容易误读的尾部

IC:4530–4543 第一遍严格 `i<20`，逐槽备份并清可消 bolt，即使前面已有 BOLT_NONE 也继续检查。第二遍是 **`i<20 && backupBolts[i]`**，不是 `monst->info.bolts[i]`；否则第0槽被清会提前停止，丢掉后面的不可消项。

还核实到一个不能擅自美化的事实：CE 第二遍**没有清理压紧后的尾部**。用合成 NOT_NEGATABLE 配置，`[NEGATION, WHIP, DISTANCE_ATTACK]` 得到 `[WHIP, DISTANCE_ATTACK, DISTANCE_ATTACK]`，最后一项重复是原函数输出。实现保留该原样行为；web 动态数组只保留首个 NONE 之前的可遍历前缀。测试覆盖备份终止、原空槽、20槽上限及原尾部。

**仓库当前 CE boltCatalog 没有任何实际条目标 BF_NOT_NEGATABLE**（全 src 检索与 W-1 catalog 同时核实）。所以真实游戏中包括箭、毒镖、蛛网、藤、blink 在内全部可消，不能把 BF_NOT_LEARNABLE 当成 BF_NOT_NEGATABLE。上述保留/重复测试临时改目录的 flag，finally 恢复；没有改生产目录或生成数据。

## 5. 永久状态与 p1_28 翻正

旧 p1_28 注释“临时剥离、到期恢复”被驳回：IC:4524 对 info.flags 永久 `&= ~NEGATABLE_TRAITS`，MC:2498 将非玩家可消状态设0，negate 尾部没有 initializeStatus/sync 调用。剩下的 trait 不需要在这里重建一整套状态。

1. `levitating == 1000` → `0`，并新增 `MONST_FLIES` 已消除断言，依据 MC:2498 + IC:4524。
2. 消魔后再放熔岩，`hp == maxHp` → `hp == 0`，依据 Time.c:183–190 的火免/悬浮判据。
3. `char != '%'` → `char == '%'`，证明死亡收口，而非只打文案。新增 W23 用例进一步在**消魔当刻**站熔岩/深渊，确认立即死亡/置 falling，不只等环境回合。

## 6. die-if-negated：来源、顺序和死亡消息

对全部 CE src 搜索 MONST_DIES_IF_NEGATED，静态目录来源：wisp、sentinel、phylactery、golem、spectral blade、spectral image、stone guardian、winged guardian、mirrored totem。**唯一实际动态 `|=` 加标点是 Combat.c:930 护甲 A_MULTIPLICITY**：克隆攻击者作为玩家谱影，随后移除 MA_CAST_SUMMON/MA_DF_ON_DEATH，改 leader、阵营、寿命等。clone 也会按值继承已有标志，但不是另一个“无条件动态加标”点。

web 的 A_MULTIPLICITY 仍未实现且在 ItemLoader 的符文映射中排除，本轮不补该系统。现有生成/召唤/克隆可带此标志者都由同一 helper 检查；测试人工加标也同样有效。

三分支按消状态之前的状态/flag 判断：

| 优先级 | 条件 | 文案 |
|---|---|---|
| 1 | 当前 STATUS_LEVITATING>0 | dissipates into thin air / 消散在空气中 |
| 2 | 否则 INANIMATE（web 也识别 TURRET 的复合位） | shatters into tiny pieces / 碎裂成无数碎片 |
| 3 | 其余 | falls to the ground, lifeless / 倒地死去 |

并非所有死亡都设 wasNegated：只有死亡前已发生 ability 剥离才会设；仅带死亡旗标的普通目标不会。死亡支跳过清状态、突变/traits/bolt、计数重置和地形，护盾也不能救命。后续掉携物和死亡清扫沿既有死亡路径，不新造伤害/战利品抽签。

## 8. 所有共用入口及行为变化

全 src 搜 negate/NEGATABLE，生产实际调用只有以下路径（私有桥接测试不算新增玩家入口）：

| 路径 | 实际调用 | 本轮变化 |
|---|---|---|
| 玩家射线接触，包括反射回玩家 | applyBoltEffect NEGATION → negateCreatureMagic | 完整逐项规则；用实际布尔返回 + **事后可见性** autoID；不再只看HP/status JSON |
| 怪物射线接触，包括反射到其他生物 | castMonsterBolt → applyMonsterBoltHit NEGATION → 同 helper | 同样剥离/保毒/死亡/地形规则，消息不重复；候选规则独立于命中规则 |
| 否定卷轴对玩家 | readItem 的 negate_burst → negationBlastFromPlayer → helper(player) | 先处理玩家，心灵/悬浮/火免降1，保留毒/瘫痪/虚弱，不发普通剥离消息 |
| 否定卷轴对怪物 | 同 blast 的视线+距离循环 → helper(monster) | 不经过射线反射，直接剥反射能力/杀纯魔法造物；无效果不发成功消息 |
| 自动选择目标 | arcanaTargetCandidates → negationWillAffectMonster | 仅已知消魔、敌方分支，未入池身份用显式 Item 测试；未知物品不泄露此过滤 |

没有独立 charm-negation 运行入口，也没有额外负面来源绕过此 helper；玩家目前由卷轴、怪物射线、反射射线触及。消魔魔杖定义仍待 W-24。
