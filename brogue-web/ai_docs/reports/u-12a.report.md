## CE 通用施法链

`monstUseMagic` 先调用 `monsterSummons`；成功就结束本次施法尝试，否则进入 `monstUseBolt`。后者无 bolt 时早退；目标顺序为玩家，然后 `monsters` 链顺序；每个目标按目录 bolt 顺序尝试。目标先过 `generallyValidBoltTarget`，然后跳过 BLINKING，再过 `specificallyValidBoltTarget`。只有两道资格门通过后才执行 `MONST_ALWAYS_USE_ABILITY || rand_percent(30)`；失败继续下一个 bolt，不丢弃当前目标。web 的 `trySummon`/`tryUseBolt` 和行动出口保留此顺序。召唤内部自己的随机调用先于 bolt 尝试；本轮没有移动它，也没有改生成路径。

一般目标门依次排自己、纷争且游荡时的玩家、盟友对献祭目标、隐藏/潜水，最后检查开放路径。web 现接休眠、隐形在气体中显形、队友互见、LOS。`isDormant` 对应 CE 摘链状态。献祭标记 `MB_MARKED_FOR_SACRIFICE` 和 `MB_SUBMERGED` 没有等价运行时簿记，见下文。这里的怪物视觉不以玩家 FOV 代替开放路径。

特定目标门在 bolt 专属 switch **之前**依次检查：友方/敌方目标旗标、敌方无敌、非盟友反射者、`forbiddenMonsterFlags`、火免、施法者脚下可燃地形烧后产物。火系烧后地形使用现有 `burnedTerrainFlagsOfCell`，以 CE `forbiddenFlagsForMonster | T_HARMFUL_TERRAIN | T_SACRED` 和物种免疫消去规则判定；只查询即时后继，不执行燃烧。HASTE/SHIELDING 另接 CE `targetEligibleForCombatBuff`：敌方施法者只给追踪气味态目标；盟友施法者需要自身可直接看见，且玩家视野中存在可见敌人。web 用 `HUNTING`、格可见性作当前状态投影。

## 阵营矩阵与回避

CE `monstersAreTeammates` 不等于同属敌方阵营：领袖/随从、同领袖随从、玩家与盟友、两名盟友才是队友。纷争不会清除这些队友关系。CE `monstersAreEnemies` 先排俘虏和自己，再判纷争，然后判深水中水栖怪对非水免/非悬浮者的敌意，最后按玩家阵营异或。web 对 bolt 门以 `isCaged`、`leader`、`isAlly`/`dominated`、`discordant` 和地形判这些条件。`monstersAreEnemies` 公共无地图签名保留基础关系，bolt 专用的 `boltEnemies` 加入深水例外。

| 场景 | BF_TARGET_ALLIES | BF_TARGET_ENEMIES |
|---|---|---|
| 普通相异敌怪、无随从关系 | 拒：非队友 | 拒：非敌人 |
| 敌怪领袖与随从 / 同领袖随从 | 准：队友且非敌人 | 拒 |
| 两名玩家盟友（含支配后）或玩家与盟友 | 准 | 拒 |
| 玩家阵营与敌方阵营 | 拒 | 准 |
| 队友一方纷争 | 拒：虽仍是队友，但也是敌人 | 准 |
| 俘虏 / 笼中怪 | 随队友关系且非敌人才准 | 拒 |
| 水栖怪与深水中非水免/非悬浮者 | 拒：即使有队友关系 | 准 |

反射规则来自 CE 2613–2617：`MONST_REFLECT_50` 或 `MA_REFLECT_100` 且目标不是 `MONSTER_ALLY`，则可反射 bolt 不射；`BF_NEVER_REFLECTS`、`BF_HALTS_BEFORE_OBSTRUCTION` 例外。已从 NEGATION 分支删除额外反射判定，公共门负责所有 bolt。火免目标不受 `BF_FIERY` 瞄准；脚下可燃物烧后会出现施法者回避的地形，也不瞄准。新增测试覆盖反射、火免、草地烧后火，以及火免施法者的反例。

## 改动与边界

改动 `src/entities/Monster.ts` 的队友/敌人关系、隐藏感知、公共 bolt 门和战斗增益资格；保留 U09 的各 bolt 专属 switch、forbidden 目录门、BLINKING 单独调度及玩家魔法执行链。删除 NEGATION 重复反射检查，并把原本抢在阵营门之前的攻击性催眠检查放回 effect switch。`tryUseBolt` 的玩家优先、怪物插入顺序、bolt 顺序和掷骰位置未改；新测试以固定两次 30% 骰核对顺序。无存档 schema 改动，也不做旧档兼容。
