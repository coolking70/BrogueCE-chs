## 5. 26层体积、读写和存储

[测量脚本](../../scripts/u03-measure.ts) 用 seed7 实际生成D1–D26，59,566个格；三次 JSON编码/解析/恢复后所有字段相等，见 [measurement.json](u-03-evidence/measurement.json)。[SaveStorage.ts](../../src/engine/Core/SaveStorage.ts) 把JSON字符串与轻量摘要放进 IndexedDB 同一 readwrite 事务，界面等待事务完成才报告成功。

最终引擎样本为 **32,445,381 UTF-8字节**（32.45 MB / 30.94 MiB），JSON字符串32,377,679码元。三轮中位数：snapshot 86.43ms、stringify 44.74ms、parse 73.78ms、load 106.21ms；各轮原值见measurement.json。浏览器含真实操作历史的样本32,465,320字节：保存86.6ms、读出并解析72.6ms、引擎恢复148.1ms。存档本来就超出小容量 localStorage，故该变更有真实容量依据；未做压缩、云端上传或多槽功能。

浏览器实际26层 JSON写入→读回逐字相等→load→再导出逐字段相等；另验证覆盖事务主动 abort 后旧世界和摘要都保留、删除同时清空二者、重新写入后页面刷新可继续至D26。性能是本机本轮样本，不是所有设备承诺；IndexedDB配额/磁盘写入失败沿用保存失败提示。
