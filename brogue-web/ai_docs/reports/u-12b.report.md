# U12b：盟友逃险、跟随与永久逃跑模式

## CE 规格核对

以 X-0 §4.3 U12、§3.1 K10 及本工作树 CE `Monsters.c:2997–3256`、`:1745–1809`、`Architect.c:1647–1657` 为准。CE `moveAlly` 依次处理危险地形、最近敌人与 `allyFlees` 撤退、施法、牵引距离及徒劳攻击、追击、尸体、追领袖或附近游荡。普通 `MONSTER_FLEEING` 是可恢复的当前状态；`MODE_PERM_FLEEING` 是独立模式。机器怪入场时两者同时设置，不能因血量恢复或远离玩家自行结束。

## 实施

- 普通盟友在施法前先逃危险地形，再依据最近敌人撤退；所有普通盟友均复用 U07/U11 已有的安全图与步行脱险逻辑。地形处理早于隐形敌人掷骰扫描。
- 选敌复用 `closestBlinkEnemy`，按盟友自身可达路径、目标阻挡和隐形资格筛选；追击复用 `allyShouldPursue` 的 4/10 格牵引、贴身延长、维持距离和徒劳目标判断。移除“玩家必须看见敌人”的旧门槛。近战几何仍先于被动趋近，尸体仍先于追领袖。
- 无目标时，独立幽灵剑游荡；普通盟友在玩家附近按 30% 概率游荡，否则先循气味，失效后向玩家寻路。保留 U07 的远距 blink 跟随和 U11 的尸体吸收。
- `Monster` 新增独立 `creatureMode`；机器 `MF_MONSTER_FLEEING` 设置永久模式；回合行动使永久逃跑者保持 `FLEEING`，普通逃跑者仍可结束。U01 实例字段、U03 快照列纳入该字段；旧快照缺字段时恢复为普通模式。

## 旧守卫冲突与修正

- `p4_5_melee_specials` 原夹具要求盟友攻击武器免疫目标且离玩家六格。CE 的 `attackWouldBeFutile` 和四格牵引都会阻止该攻击。初次全测在此失败，证明旧前提依赖旧 AI。仅把玩家移入牵引范围，并将实际近战结果限定为命中但零伤害，保留“击退调用不以 `damage>0` 为门槛”的原断言。
- `w_17_domination` 原夹具把已支配盟友放在玩家五格外，同时要求其追击旧同伴；初次全测失败。仅把玩家移入牵引范围，继续验证转阵营后攻击与敌方反击。
- 新增 `u_12b_ally_mode`：覆盖玩家视野外可达敌人、低血盟友先撤退、永久模式存档往返、旧档默认普通模式、普通逃跑结束。

## 范围边界

CE 偷窃者只在**实际偷得物品**后设置 `MODE_PERM_FLEEING`（`Combat.c:480–510`）。web 当前 `MA_HIT_STEAL_FLEE` 分支尚无真实偷物动作，本轮没有把该占位分支改为永久模式。web 普通敌人的完整 `updateMonsterState` 感知与恐惧谱系仍非 CE 全量；本轮保证永久模式不会走普通恢复出口。被动趋近、领袖气味与占格细节沿用现有 web 辅助函数，未宣称逐骰流完全等价。
