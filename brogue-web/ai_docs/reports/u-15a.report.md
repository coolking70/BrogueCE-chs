## 2. IMPREGNABLE 来源清单

不是某个 TerrainType 自带，也不是有 machineNumber 就不可破。web 生产赋值只有 BlueprintEngine 两处 `.add`，都写同一个 `Grid.impregnableCells`（键 `y * DCOLS + x`）：

1. `BP_IMPREGNABLE`：准备 interior 时，跳过 gate site，将 interior 格和其八邻域内的图内、非 interior、非 gate 格置位（BlueprintEngine:1293–1303）。包括地板、机器内部及外围墙，非仅墙。
2. `MF_IMPREGNABLE`：feature 成功落位后给实际落点置位（:1609–1611）；地形类别不能代替此旗标。
