## 1. CE 全路径与实际实现

| bolt | CE effect / magnitude | pathDF | targetDF | forbiddenMonsterFlags | BF 旗标 |
|---|---|---|---|---|---|
| SPIDERWEB | BE_NONE / 10 | DF_WEB_SMALL：SPIDERWEB / SURFACE / 15 / 12 | DF_WEB_LARGE：SPIDERWEB / SURFACE / 100 / 39 | IMMOBILE、IMMUNE_TO_WEBS | TARGET_ENEMIES、NEVER_REFLECTS、NOT_LEARNABLE |
| ANCIENT_SPIRIT_VINES | BE_NONE / 5 | DF_ANCIENT_SPIRIT_GRASS：同名草 / SURFACE / 50 / 47 | DF_ANCIENT_SPIRIT_VINES：同名藤 / SURFACE / 75 / 70 | INANIMATE、IMMUNE_TO_WEBS | TARGET_ENEMIES、NEVER_REFLECTS |

表中 DF 后两个数字为 startProbability / probabilityDecrement。来源：`variants/GlobalsBrogue.c:83,88`、`brogue/Globals.c:681–685`、`Rogue.h:1534–1539`。四个 DF ID 为 **57、58、60、59**，没有 DFF 标记、subsequentDF、聚怪、光焰或怪物生成。任务检索词 **DF_SPIDERWEB 不是当前 CE 的 DF 名称**；实际是 WEB_SMALL/WEB_LARGE，反查已包含这些名称。

- `monstUseBolt → monsterCastSpell → zap`：Monsters.c:2786–2815/2769–2783。`zap` 的坐标序列不把原点作为第一格，射线延伸到碰撞或地图边界，不以请求坐标强制终止。
- `updateBolt`：Items.c:5419–5468。生物接触使非穿透 bolt 标记终止，但**当前格的 pathDF 仍执行**；再按火、电分支处理，然后返回终止值。没有生物时也每格执行 pathDF。
- `zap`：Items.c:5707、5787–5811。两者都不含 PASSES_THRU_CREATURES、HALTS_BEFORE_OBSTRUCTION，也不反射。撞到生物或墙才停，**墙本身是到达格**，不是墙前一格；沿路、终点的地形可扩散到射线路径外。
- `detonateBolt`：Items.c:5562–5564/5872。在**实际落点**再执行 targetDF，不在原请求目标强行铺设。BE_NONE 的铺设本身不设置 autoID。
- `spawnMapDF → fillSpawnMap`：Architect.c:3278–3330、3210–3276。四邻概率波前、减概率、优先级 `old >= new`、SURFACE 阻挡由原 DF 库处理；墙不能落 SURFACE，但以墙为种子可向旁边合法格扩散。原点虽不被射线更新，邻格 DF 扩散仍可能覆盖施法者脚下。

web：Bolt.ts 将两项映射到 `BoltEffect.NONE`；Game.castMonsterBolt 复用原 traceBolt，applyBoltTerrainAt 执行四项白名单内的 pathDF，trace 后对 landingPos 执行 targetDF。未开启其他未登记魔法，也没有替换轨迹、反射或伤害算法。蜘蛛动画为白色 `*`、藤蔓动画为草字符；中文日志已接现有词表。BE_NONE 无直接命中伤害。

## 2. 地形生命周期、占格与死亡

| 地形 | 属性 | 接触与后继 |
|---|---|---|
| WEB（CE SPIDERWEB，既有载体） | priority19、ignition100；ENTANGLES / FLAMMABLE；STAND / VANISHES / VISUALLY_DISTINCT | 无自动衰老；点燃 → DF_PLAIN_FIRE。接触使用既有地形阻滞近似 |
| ANCIENT_SPIRIT_VINES（新增尾部枚举135） | priority19、ignition100；ENTANGLES / CAUSES_DAMAGE / FLAMMABLE；STAND / VANISHES / VISUALLY_DISTINCT / PROMOTES_ON_PLAYER_ENTRY | 自发晋升阈值1000；晋升 → DF_ANCIENT_SPIRIT_GRASS；点燃 → DF_PLAIN_FIRE |
| ANCIENT_SPIRIT_GRASS（新增尾部枚举136） | priority60、ignition15；FLAMMABLE / STAND；promoteChance0 | 留在 SURFACE，无攻击或实体寿命；点燃 → DF_PLAIN_FIRE |

CE：Globals.c:470、525–526；Time.c:290–341、592–640、1619–1664。藤蔓和草都不占怪物名额、不创建领袖/召唤物。生物可站在这些地形上，藤蔓与怪物不会争夺一个“实体位置”。**玩家即时接触藤蔓会先晋升成草，悬浮不豁免此晋升**；因此古灵对玩家的实际落点通常变成草，周围仍可能保留藤。怪物没有这一玩家专属晋升。

实现补齐：

1. 新 terrain flags、SURFACE 归属、drawPriority、可见外观与名称；旧枚举数值和旧目录行保持不变。
2. DF 的 opt-in `onBuiltCell` 在每格成功铺下之后、下一格之前调用，顺序对齐 CE fillSpawnMap 的即时接触。U08 调用只处理玩家脚下藤蔓晋升；失败落格不调用。普通生成调用不传回调。
3. 正常玩家步入及现有魔法位移入口均晋升藤；自然衰老复用原 Promotion 的 `rand_range(0,10000) < 1000`，不是新造倒计时。草后继的概率扩散可以继续铺草，但不能覆盖更高优先级的藤。
4. 持续伤害原来只检查 GAS 层，现按 CE 四层顺序寻找首个 CAUSES_DAMAGE，**每次客观结算只扣一次** `max(1, floor(maxHp/15))`。藤与毒气叠层不双扣；瞬时接触不扣此伤害；绕过护盾。INANIMATE/INVULNERABLE 豁免，悬浮、单纯免疫蛛网不豁免伤害。玩家 respiration 仍豁免并鉴定；增加藤蔓死因。怪物死亡走既有 die/removeDeadMonsters，无新尸体/学习事务。
5. 网移动近似改读四层 ENTANGLES，怪物尊重 IMMUNE_TO_WEBS/INVULNERABLE；挣脱仅清 SURFACE，保留地基和液体。清层收口在 Promotion.breakEntanglingTerrain；源码扫描白名单未改。
6. 当前 schema 的快照保存四层已有整数枚举，可往返新地形及原怪物占位；没有旧存档迁移。

## 3. AI、学习资格及明确边界

`specificallyValidBoltTarget` 接 BE_NONE 分支：沿用敌方/无敌资格；分别消费上述两个 bolt 的 forbidden 标记（含 TURRET 对 IMMOBILE 的复合语义）；以当前脚下 ENTANGLES 近似 CE STATUS_STUCK，避免向已缠住目标重复施放。CE Monsters.c:2655–2675 的后一个 avoided-terrain 条件，在这两条 targetDF 都带 ENTANGLES、且 IMMUNE_TO_WEBS 已被前置 forbidden 门拒绝时不再增加限制。

施法调度本身没有重写：玩家优先，再按 monster 列表顺序；bolts 顺序不变；合法目标后 `ALWAYS_USE_ABILITY || rand_percent(30)`；蜘蛛和古灵原目录都有 ALWAYS_USE_ABILITY。蜘蛛 attackSpeed200 + CAST_SPELLS_SLOWLY，成功消耗400 tick；古灵100 tick。失败不改 ticks。沉睡不进普通施法；隐形/视线门继承现有通用 AI。

学习资格仍来自 CE 旗标：**SPIDERWEB 不可学，VINES 可学且现在有执行出口**。另测手工安装 vines 的普通盟友能施放，newPowerCount 不被消费。没有实现选择尸体、吸收、安装能力或扣学习额度。

保留事项：

- **U14b/U18**：没有 STATUS_STUCK/maxStatus[STUCK]。CE Time.c:319 的3–7计数、Movement.c:1402–1420/Monsters.c:3773–3784 的尝试移动递减，仍由现有50%挣扎、挣扎时20%破网近似替代；“站在缠绕地形”也不完全等于 CE 的已有 STUCK 状态。攻击目标占格时的挣脱顺序、潜水 MB_SUBMERGED 及 STUCK 随位移清理待后续。
- **U17**：只接 U08 所需的逐格玩家晋升、渲染/视野刷新及 pathingChanged 消费。四个 DF 都没有疏散/聚怪/休眠唤醒/后继标记，所以不为它们新建这些事务。通用 refreshCell、物品燃烧、flavorMessage、通用后继回调传播及其他 DF 副作用未宣称完成。后继草扩散落格时也未新增通用再次接触事务（例如复合陷阱/岩浆局面的再次即时判定），仍需U17统一接线。火/晋升沿用现有已落地链。
- **U12/U09**：通用 generallyValidBoltTarget 的隐形气体描边、潜水/献祭资格和完整 openPathBetween 等既有差异未重写；本轮只补两种地形 bolt 的专项资格。没有宣称整个怪物施法 AI 对齐。
- **W-22 恢复**：U07 与 U08 的缺执行出口前置已解决；仍需 U09 学习消费者矩阵、U10 吸收字段及持久化、U11 完整学习状态机。U14b 的网计数是本效果保留的明确近似。
