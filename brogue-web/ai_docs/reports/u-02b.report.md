# U02b：CE 分层种子隔离与 64 位 raninit

2026-09-25；规格为 X-0 §4.2 U02、§3.1 K04 和 U02a §6；本工作树 CE 原文优先。实现完整 uint64 初始化、交错层种子表、新层 oldSeed 回切及 waypoint 消费边界，并保留当前层无损 RNG 存读。**不宣称 CE 与 web 同种子整张地图相同；未实现 U03 整局跨层存档。**

**交付状态：实现与独立对照完成；最终回归仍有3条旧守卫失败，均属§6所列待裁决期望，未擅自迁移。构建、drift及本轮22项专项通过。**

## 1. CE 路径复核

复核 `Math.c:90–194`、`RogueMain.c:232–313,675–817`、`Monsters.c:1587`、`Recordings.c:720,1428`、`Rogue.h:2577`、`variants/GlobalsBrogue.c:44,1016`。

- raninit 用低位初始化 b/c/d，仅 c XOR 高位，再 warmup 20 次；原 ranval、range 拒绝采样未改。
- rand_64bits 在**当前选择流**上原始取数两次，先 hi 后 lo；SUBSTANTIVE 逻辑计数一次。web 的 COSMETIC 逻辑计数也一次，属于已有观测扩展。
- initializeRogue 的层表为 `i=0…deepestLevel`。当前 CE Brogue deepestLevel=40，因此实际抽 **41 槽**，不能按 web 的 26 个可玩层只抽 27 槽。每槽先 levelSeed（高位非零用 rand64bits，否则低抽+10000×高抽），0 改 i+1；随后抽下梯 x/y，拒绝太近的坐标，再传下一个 upStairsLoc。**distanceBetween 是 Chebyshev 距离，不是欧氏距离**；`DCOLS/3` 为 C 整除26。两侧尺寸均79×29。
- 新层抽非零 oldSeed → 用 levelSeed 重播两流 → dig/populate/waypoint 等 → 用 oldSeed 重播两流。回切不是恢复8个状态字。CE 随后才做50步环境预热；重访不进播种分支，其 waypoint 消费当前流。
- CE seedRandomGenerator 不清计数；新录像/回放初始化单独清零。web 新局和录像重建统一由 startNewGame 显式 resetCounters。

[提取脚本](../../scripts/u02b-ce-reference.mjs) 编译 CE 原文中的 RNG 函数及层表随机消费块，未用 web 生成黄金值。[C 提取件](u-02b-evidence/ce-reference.c)、[9组结果](u-02b-evidence/ce-reference.json)、[CE源哈希](u-02b-evidence/ce-sources.json)。9组种子覆盖7、4个基线seed、2^32、2^40+7、2^53+1、最大uint64；对照两流初态、8个raw64结果、41槽完整种子/预抽上下梯、末态及逻辑计数，全部一致。

**可比量边界：**这里取得的是 CE initializeRogue 的第一层及全部后层**预抽**楼梯坐标，不是执行完整 digDungeon/placeStairs 后的最终楼梯。web 的实际放梯仍有 U04 差异；没有运行完整 CE 同种子第1层地图，故不报最终楼梯位置一致。

## 2. 实现与存档合同

- `Random.ts`：初始化边界接 bigint，完整 uint64 拆词；新增 `rand64bits(): bigint`、`resetCounters()`；seedRandomGenerator 保留选择器和双计数、同时初始化两流。
- 新 `Core/LevelSeeds.ts`：CE41槽种子/预抽楼梯初始化、深拷贝和载荷校验。`Game.levelSeeds[d-1]` 是层元数据，不与 `Game.levels` 的已生成世界缓存混用。
- startNewGame 先切 SUBSTANTIVE、播种、清计数、初始化整个表，再走既有外观/玩家/生成入口。high=0保留两次0…9999抽取，high≠0接raw64；两分支生成0都改槽号+1。
- generateDepth 新层分支包围 Architect、populate、机器实化、坠层幸存者落位和 waypoint；try/finally 保证异常也用 oldSeed 回切，成功才 visited=true。首层和后层走同一边界；缓存重访不取oldSeed、不重播种，waypoint直接消费当前流。
- 原楼梯牌堆按**上一层玩家位置**排除邻域，即使只隔离 RNG 仍能污染后层地形。本轮保持排除形状，锚点改成当前槽固定 upStairsLoc；它是稳定的生成输入，不声称实际放梯已对齐 CE。
- WaypointMap 删除内部快照/恢复；旧 duringPlay 参数仅保留调用兼容，所有调用都真实消费所选流。Game决定新层隔离，重访/掘地没有这层隔离；读档仍直接恢复保存的 waypoint 产物，不重抽。

RNG 载荷 `version:2`、`algorithm:'brogue-web-ranval32-uint64-level-v2'`。GameSnapshot 仍用既有 v2 外壳，新增**必需** `levelSeeds` 数组：每槽 `levelSeed`（规范非零十进制uint64字符串）、`visited`、`upStairsLoc/downStairsLoc`。数组及坐标双向深拷贝；缺表、长度错误、稀疏槽、零/非法种子、非法visited/坐标以及旧 RNG 算法全部拒绝。App存档摘要也检查新标签及层表，避免展示无法加载的旧档。

**不做旧存档兼容。**当前层JSON没有其他已访层的世界缓存。载入后再请求缺失的已访层会明确报错，不能把它当未访层重生。后续未访层可用原层种子，但计量等全局状态还未完整保存，不据此承诺读档后的所有跨层产物一致。

[专项](../../src/test/u_02b_level_rng.test.ts) 最终22项：CE9组；raw64两次原始取数且只计一次；两种levelSeed=0替换；楼梯拒绝采样顺序；混合raw64/range双流JSON续抽；首层/后层/活动层及读档复入/oldSeed=0重试/回切先于vision；waypoint计数；重访无播种；异常回切；表深拷贝/拒旧；3个seed动作隔离。

该保证限于地形生成随机输入及已验地形字段，**不扩大成“交互不影响后层一切产物”**：坠层对象、物品计量/库存、奖励房配额等非RNG状态仍有真实跨层语义；U03也尚未保存这些全部状态。
