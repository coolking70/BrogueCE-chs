# U24：文案与 i18n 校正报告

依据：`x-0-survey.report.md` §3.1 K26/K41、§4.1、§4.4 U24；本轮仅改文字、翻译和扫描守卫，不改玩法或生成流。

## 问题清单与处理

| 出口 | 核实结果与处理 |
|---|---|
| 发现屏 | `getDiscoveries()` 原把数据中的英文 `trueName` 直接大写。现先走与背包相同的 `ItemLoader.translateName`，浏览器中卷轴、戒指、药水、法杖、魔杖均显示中文。 |
| 符文与浮字 | 已识别符文的物品名、详情标题和觉醒日志原显示 `paralyzing` 等内部 ID；现由 `runic.name.*` 译名。`Ally!`、`Paralyzed`、`Confused`、`Force!` 浮字改为翻译调用；数字伤害/治疗浮字保留数值。 |
| 侧栏和操作 | 饥饿分级、深度、生命、食物、状态、日志改用翻译键。浏览器中可见的按钮及其无障碍标签、详情关闭提示也已本地化。 |
| 菜单与背包 | 真实浏览器暴露菜单和背包中的英文 `defaultValue`：原 P1-30 扫描器漏扫 `useTranslation()` 取得的 `t`。现补键、扩扫描范围，并改背包分类名。回放控制按钮也补译。 |
| 描述语义 | `staff_of_light` 退池旧说明宣称致盲；改为退池说明。护符说明按当前执行效果校正：生命最多 8 HP、速度护符实际施加悬浮、防护随机免疫一种负面状态；心灵感应和火免护符目前只扣冷却，明确写出没有相应状态效果。戒指说明按当前佩戴消费者校正，未实现的潜行、转移、千里眼效果不再作出虚假承诺。生命药水、混乱药水、退池药水及芒果等文字按当前饮用/食用分支校正。符文详情中固定比例、物种限定、毒效果等与实际执行不符的承诺已改。剧毒符文即时伤害与中毒浓度分别使用不同日志键；突刺日志按命中与“猛烈突刺”呈现。 |
| 变量 | 新增/改动的 `sidebar.depth`、`machine.sign`、`combat.lunge_hit`、`runic.weapon.venom*` 等均保留对应插值参数。浏览器渲染与 P1-30 测试验证了真实资源路径。 |

任务书要求描述**当前实现**；CE 的护符和部分符文规则与 web 仍有差距（X-0 K23/K24/K26）。本轮文字按实际消费者编写，未把文案当作规则迁移。后续玩法轮完成后需再校正文案。

## 硬串守卫

新增 `src/test/u24_hardcoded_text.test.ts`：用 TypeScript AST 扫描生产 `.ts` 与 Vue 脚本中的 `spawnFloatingText` / `logger.log` 首参，拒绝直接传入包含中英文的字符串或模板文字；遍历所有 Vue 模板的静态文本节点，拒绝未登记的中英文直写。数值浮字及标点不视为语言文本。另有真实 `zh_CN` 资源集成断言，检查发现屏中文名和已识别符文名/详情标题均不露内部 ID。

白名单：`AgentControls.vue` 的 `sr-only` 深度、坐标、HP、距离等英文状态字段供自动化消费者读取，不在视觉界面显示；`Sidebar.vue` 的 `BROGUE` / `JS` 是品牌名，`x` 是日志重复次数记号；浮字 `!` / `?` 是无语言符号。白名单按文件和原文字精确匹配，不按宽泛正则放行。

P1-30 的键扫描器扩到 `useTranslation()` 的 `t()`，并识别 Vue 绑定属性内的字面量翻译键；因此菜单、背包、回放的英文回退会亮红。已保留既有死键检查；本轮没有删除翻译键，无需迁入 `zh_CN.legacy.json`。
