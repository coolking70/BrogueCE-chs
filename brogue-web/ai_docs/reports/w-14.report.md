## 1. CE 怎么铺力场，W-1 的零 DF 契约

权威为仓库内 `BrogueCE-master`：

- `variants/GlobalsBrogue.c:76` 的 obstruction bolt：`BE_OBSTRUCTION`、magnitude=10、`pathDF=0,targetDF=0`、`BF_HALTS_BEFORE_OBSTRUCTION`。
- `brogue/Items.c:5474–5493`：**detonateBolt** 在最终落点复制 `dungeonFeatureCatalog[DF_FORCEFIELD]`，改 `probabilityDecrement`，调用 `spawnDungeonFeature(x,y,&feat,true,false)`，无条件置 autoID。
- 这里的 true 是 refreshCell，false 是 abortIfBlocking。普通 `targetDF` 消费在 switch 后 `:5562–5564`，不是阻障的入口。

因此“不强依赖 pathDF 非零”不是可以随便补一个固定 pathDF：**两个零字段原样保留**，新接的是动态落点效果。Game 在 onCell 阶段跳过 OBSTRUCTION 的效果分派，保留既有逐格地形暴露/碰撞/反射，trace 结束后只结算一次阻障。非贴脸障碍/生物之前停，第一格仍按 W-3 的 CE 例外处理；同起终点无落点、无消耗、无 autoID。贴脸反射沿实际回程落点生成。

## 2. 原行与 E 公式

`Globals.c:674` 原行为 `{FORCEFIELD,SURFACE,100,50,0}`；`Rogue.h:1526` 枚举值 **51**。DungeonFeatureCatalog 新增 DF_FORCEFIELD，尾部省略字段按 0 投影为 null/空串；不改 FORCEFIELD_MELT(52)。`catalogFeature` 返回副本，施法不会污染共享目录的 100/50。

`Items.c:5479–5489` 的定点查表按原字面值复制，`FP_FACTOR=65536`：

```text
i = min(40,E) - 2
probabilityDecrement = max(1, floor(75 * POW_OBSTRUCTION[i] / 65536))
```

`Promotion.spawnObstruction` 调既有 `spawnDungeonFeature → spawnMapDF → fillSpawnMap`。`Architect.c:3288–3328` 的四向概率波前从100开始，每代减上述数值；扫描顺序/重复波前/RNG均复用原移植，不设半径、面积或铺设格数上限。E2的候选概率为100、53、6；测试同时固定这些真实调用参数，并以12个seed的E2/E3/E8实际面积/随机调用总量排除固定范围实现。定点衰减不是消融寿命。

## 4. 消融、占位与 IMPREGNABLE

`Globals.c:477–478`：FORCEFIELD 和 MELT 均在 SURFACE 阻通行/气体/对角、不阻视线，带 TM_STAND_IN_TILE、TM_VANISHES_UPON_PROMOTION、TM_PROMOTES_ON_CREATURE。原 promoteChance 分别为 **-200/-10000**，链为 FORCEFIELD → DF_FORCEFIELD_MELT → NOTHING。

`Time.c:1622–1663`（web runPromotionUpdate）：每个正交邻居满足“在图内、可通行、同层不同tile”才贡献200/10000；按 `rand_range(0,10000)<chance` 记账，再第二趟执行晋升。不是固定 N 回合计时，封闭内部必须等边缘打开。本轮不改该驱动/目录数值。测试验证边缘先变MELT、内部仍是FORCEFIELD、再逐层消失；真实 objectiveTimeBlock 和存档往返也验证此链。

CE `Architect.c:3208–3276/3278–3329` 的扩散/填充 **不检查 IMPREGNABLE**。保护标记地板照样可铺；非原点扩散候选和填充格通过 `T_OBSTRUCTS_SURFACE_EFFECTS` 排除墙，检查是全层 OR，并非仅 DUNGEON。CE 原点的 spawnMap 无条件置1，所以贴脸墙仍可向旁边合格格扩散，只是墙自身不铺；零铺设用例用四面封闭的墙控制这一边界。W-13 的 Grid.impregnableCells 不需新接阻障排除门，测试固定保护地板可铺、保护墙不可铺、GAS层合成阻挡也不可铺、液体/气体/体积/机器编号/保护标记保留。

CE `fillSpawnMap(refresh=true)` 对实际铺设格上的生物执行即时地形效果；`Time.c:273–288` 不豁免飞行者。FORCEFIELD 的 promoteTile 又以 refresh=true 生成MELT，递归刷新使占位格立即走完 **FORCEFIELD→MELT→NOTHING**，不搬走生物、不伤血。

**旧原语缺口如实登记**：`ai_docs/c_4b_dungeon_feature_report.md:219` 已写 refreshCell 不入 web DF 签名、“由调用方负责”。本輪在新的 spawnObstruction 语义入口对实际 builtCells 的玩家/活跃怪占位，调用既有 promoteTile 完成力场链；休眠/死亡怪不冒充有效占位。这个适配仅保证新力场的占位晋升，没有宣称已补齐通用 DF refresh 的所有旧地形伤害/压力板/消息/物品点燃副作用；那些共用原语缺口仍登记，不把它们全局改动混入 W-14。
