# U15d-1 武器符文效果 CE 化报告

## 依据与边界

依据 `ai_docs/reports/x-0-survey.report.md` §3.1 K24、§4.3 U15d，以及本地 `BrogueCE-master/src/brogue/Combat.c:644-859`、`PowerTables.c:99-104,220-345`、`Globals.c:1416-1433`。本轮仅改武器符文命中效果；`ItemLoader` 的生成映射及护甲符文未动，因此 `test:drift` 的既有生成流不受新符文入池影响。

CE 冲突裁定：K24 的“mercy 复活至 1HP”是对旧 web 分支的描述，不是 CE 规则。CE `magicWeaponHit` 调用 `heal(defender, onHitMercyHealPercent, false)`；`GlobalsBrogue.c:1038` 给出 50，`Items.c:4666` 为 `min(maxHP,currentHP + 50*maxHP/100)`，整数截断。本轮实现为目标恢复最大 HP 的 50%，不复活已死目标。

## 实施

- `Combat.ts`：命中伤害结算后，按 CE `magicWeaponHit` 决定是否掷符文骰；普通符文对已死/无生命/无敌目标零掷骰，迅捷和繁衍允许对刚被杀死的目标掷骰；斩杀按 `vorpalEnemy` 物种类别判 100%/0%，再应用背刺修正。传递迟滞/迅捷武器旗标给既有 16.16 定点触发率公式。
- `CombatFormulas.ts`：加入 W_MULTIPLICITY 与 W_SLOWING 的 CE 原表，修正减速、混乱、击退距离、谱影数量/时长的整数公式。
- `MonsterClass.ts`：按 CE `monsterClassCatalog` 写物种成员表；处理 web 数据命名差异（`goblin_warlord`、`acidic_jelly`、`wisp`）。`Game.ts` 的武器酸蚀豁免亦复用同一斩杀类别门。
- `Game.ts`：移除未触发后再次走固定概率的旧路径；迅捷给玩家 `ticksUntilTurn=-1` 免费行动，跳过攻击耗时记账；即死、麻痹、减速、混乱、击退碰撞、慈悲、增殖和繁衍走 CE 效果。繁衍的谱影使用 U16 已有 `lifespan_remaining`/`MONST_DIES_IF_NEGATED` 生命周期，并继承武器的攻击旗标。首次揭示符文时显示鉴定消息。
- `zh_CN.json`：更新迅捷文案，补新符文名与鉴定文案；旧固定概率路径删除后，把不再引用的 `runic.weapon.venom_damage` 移入 legacy 词表以满足 P1-30。存档使用已有 `ITEM_FIELDS` 的 `runicType`、`runicKnown`、`vorpalEnemy` 和 U16 怪物状态字段；未加新字段，不做旧档迁移。

## 黄金值与 RNG

`src/test/u_15d_weapon_runic.test.ts` 使用 CE 3–4 基伤武器、净附魔 1/3/6 的黄金触发率：

| 符文 | 1 | 3 | 6 | 效果终态 |
| --- | ---: | ---: | ---: | --- |
| SPEED | 13% | 36% | 59% | 免费玩家行动；不追加伤害 |
| QUIETUS | 5% | 15% | 27% | 目标即死 |
| PARALYSIS | 6% | 17% | 31% | 麻痹 2/3/5 回合 |
| MULTIPLICITY | 12% | 34% | 56% | 1/1/2 谱影，均存活 3 回合 |
| SLOWING | 11% | 32% | 53% | 减速 3/8/21 回合 |
| CONFUSION | 9% | 26% | 45% | 混乱 3/4/9 回合 |
| FORCE | 12% | 34% | 56% | 最远击退 4/8/14 格，提前撞击按已飞距离伤害 |
| SLAYING | 类别门 | 类别门 | 类别门 | 同类 100%，异类 0%，即死 |
| MERCY | 15% | 15% | 15% | 恢复目标最大 HP 的 50% |
| PLENTY | 15% | 15% | 15% | 克隆存活目标 |

测试覆盖成功普通命中每个符文恰好一次概率掷骰，斩杀类别不匹配为零次，类别匹配为一次 100% 掷骰；致命命中只允许迅捷/繁衍掷骰。效果层测试覆盖迅捷免费行动、慈悲治疗、三种状态持续期、即死、击退、繁衍谱影及 U16 消魔资格、增殖克隆、`vorpalEnemy` 存档往返。web 怪物数据有自定义 `statusImmunities`，其中老鼠免疫混乱；CE 武器符文直接写状态数组，因此本轮的麻痹/混乱符文绕过该 web 限制，反事实由老鼠混乱终态测试锁定。

## 已知界限

生成映射及护甲符文依任务书明确留到后续轮次。谱影通过既有 `bladeSpawnLocation` 近路生成；CE `getQualifyingPathLocNear` 的全部地形资格与 `generateMonster` 内部 RNG 细节在 web 尚无逐值对照，因此本轮仅锁定符文触发掷骰数、实体数量和生命周期。击退沿现有网格逐格移动，增加 CE 的提前碰撞距离伤害；完整闪烁弹道/视觉动画仍取决于既有 bolt 机制。
