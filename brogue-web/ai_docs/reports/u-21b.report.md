## 1. CE 路径与改动

- `Rogue.h:127,168,174`：`COLS=100`、侧栏 20、隔列 1，故 `DCOLS=79`。`Globals.c:1007/1009` 的爆炸、传送光半径为 `DCOLS*100=7900`；`RogueMain.c:666-670` 的矿灯基础半径从 `(DCOLS-1)*FP_FACTOR` 起逐次乘 85/100，再加 2.25 格。web 的 `CE_DCOLS`、两个目录半径和所有由基础半径派生的数值现按 79 计算。
- `Light.c:120-154`：先用 `lightMultiplier` 放大或缩小，再按 `STATUS_DARKNESS/maxStatus` 的定点三次方衰减（最低 1/20），最后在水中减半；径向衰减独立按倍率和黑暗 fraction 算。web 原公式保留，`Game.refreshMinersLight` 现传 U14a 黑暗载体、当前格深水判据（`Time.c:84-107` 的深水且非漂浮、非缠绕、非阻挡）。
- `Items.c:8685-8728` 光明戒指会改变倍率；当前 web `arcana.json` 没有 `ring_of_light` 可生成项，故游戏内仍取 CE 无戒指基值 1，公式的正负倍率分支由编译 CE 黄金值测试覆盖，目录/附魔生命周期留 U15b。
- `Light.c:208-270`：地形光之后先给生物固有光和突变光，再给燃烧光、矿灯。根据 `Globals.c:1025-1162,1396-1414` 给 web 已有物种增加固有光目录映射，爆炸突变增加光映射。`monsterRevealed` 的心灵感应光、休眠怪心灵感应光和 `Light.c:289` 后的 flare 动画尚无忠实载体，登记于 §4。

## 3. 黑暗与潜行消费链

`potion_of_darkness` 在 web 目录中但不进入随机生成池。真实 `quaffItem` 入口施加 400 并调用 `updateVision`；后者每次重算矿灯后刷新 FOV。客观 100-tick 块在 `tickCreatureStatuses` 递减时刷新，1→0 当场恢复；生命药水清黑暗后已调用视野刷新；消魔对玩家清黑暗时新增即时刷新。深水进入/离开与漂浮变化由每次 `updateVision` 的当前位置重新派生。`playerTurnEnded` 在 `calculateStealthRange` 前刷新光，故潜行读取的是新光与阴影。

定向测试从 `ItemLoader.spawnPotion → inventory → Game.quaffItem` 走真实饮用方法：D20 开阔格的目标格由可见变不可见，黑暗到期后恢复；另核深水减半/漂浮恢复、Wisp 固有光在 D40 点亮矿灯外格。该药水仍是合成入包，不声称自然生成可取得。
