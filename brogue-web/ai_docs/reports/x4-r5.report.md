## 2. 选择语义与防泄漏

`getTerrainDescription(terrain, options?, locale?)` 返回真实 CE 描述的中文译文；`terrainTextId` 处理明确的显形和 D1 出口上下文。秘密地形默认使用 CE 自带的墙／地面伪装描述。`secretsRevealed: true` 只投影 CE discoverType 对应的显形地形，不改变任何格子；休眠机器和隐藏石桥不因为这个标志提前揭示。

`selectTerrainTextLayer(layers)` 复用现有 `highestPriorityLayerOf`，符合 `Movement.c:64–80`：按 DUNGEON、LIQUID、GAS、SURFACE 遍历，忽略 NOTHING，drawPriority 越小越优先，同值保留较早层。气体参与比较，**并非有气体就总选气体**。`tileFlavor(layers, options?, locale?)` 对选中层直接取风味；选中层为空串时不向下寻找非空文字，与 `Movement.c:105–108` 一致。

`selectKnownTerrain(view)`／`describeTerrain(view, locale?)` 接受 `{ visible?, remembered? }`，每个快照包含 `layers?`／旧存档回退 `terrain?` 及自己的选项。只有调用方确认可观察时才能提供 `visible`；否则仅提供 `remembered`。没有快照返回 null，不能退回实时地形。四层全为 NOTHING 的有效快照也不能被旧的单地形记忆覆盖。该接口不读取 Game、Cell、FOV 或全局语言状态，不推进随机数和回合。

CE `TRAP_DOOR_HIDDEN` 的风味原文本身是坠落消息。为完整保留 CE 的站立／接触语义，`tileFlavor` 可以返回该原文译文；**检视／记忆使用 `describeTerrain`**，对仍隐藏的陷阱门返回“地面”及空风味，防止借接触文案泄密。

`ANCIENT_SPIRIT_VINES`／`ANCIENT_SPIRIT_GRASS` 的名称和风味已进入 `content:terrain.<CE_ID>.description/flavor`，中文为“带刺的藤蔓”／“一丛草”。Game 内旧英文 return 的替换交给 R6。

## 3. 翻译来源

优先复用 `BrogueCE-master/bin/assets/zh_CN.merged.json` 的完整中文译文，同时检查其它 `zh_CN*.json` 与 web 现有语言风格。按不同英文源字符串去重：251 条直接复用 merged 译文，51 条经人工补译或校正，23 条吸收状态词逐项翻译（其中“正在进行仪式”沿用既有译法）。此统计是不同源字符串数，不是目录条目数；同一句会被多个状态／地形复用。

修正了资源中的英中文混排（例如 brimstone、brazier、luminescent、ornate）、“lava→燕岩”、将火光漏译成普通闪光、祭坛“放回取走的物品”的语义，以及地衣风味中原文没有的额外规则陈述。两条警报保留“沉重咔哒声＋开始洪水”与“低沉隆隆声＋开始坍塌”的区别。全部新增玩家文本均为中文，无英文字母残留。

8 条专属召唤句对应：`MK_GOBLIN_CONJURER`、`MK_OGRE_SHAMAN`、`MK_LICH`、`MK_PHYLACTERY`、`MK_GOBLIN_CHIEFTAN`、`MK_VAMPIRE`、`MK_ELDRITCH_TOTEM`、`MK_PHOENIX_EGG`。保留 CE `CHIEFTAN` 的拼写，web 通过 `goblin_warlord` 对接。`Warden_of_Yendor` 的大小写和其它物种别名均在查询边界归一化。
