## 1. 实现与 CE 复核

普通跟随与环境补跑分别实施和采样。实现位于 [LevelTravel.ts](../../src/engine/Movement/LevelTravel.ts)、[Game.ts](../../src/engine/Core/Game.ts)；新载体进入 [Monster.ts](../../src/entities/Monster.ts)、[EntitySnapshot.ts](../../src/engine/Core/EntitySnapshot.ts) 和层快照。

| CE 路径 | 本轮行为 |
|---|---|
| `RogueMain.c:570–617` | 步行/飞行两张距离图，八方向、墙角阻断、可用密门、不可穿过免伤且静止的怪物；坑边先找首个安全邻格作为寻路原点。追踪者/盟友资格，俘虏、禁止用梯、水生、墙内、入迷、麻痹等排除；坑降只有健康盟友或悬浮追踪者参与。web 的 HUNTING 对应 TRACKING_SCENT，isAlly 对应 ALLY；处于 FLEEING 的盟友不冒充 CE ALLY。 |
| 同上 | `floor(distance * movementSpeed / 100) + 1` 限制在 1…150；不可达盟友仍取150，普通敌人不可达不排队。记录进入倒计时和三种方向位。不会直接复制“附近盟友”到下一层。 |
| `Time.c:2182–2205,2702` | 每个客观块只扫描已访的相邻上下层；大于1先减一，等于1才迁入。环境补跑和 JSON 读取均不推进此倒计时。 |
| `Time.c:2101–2180` | 从对应入口梯或来源层坑出口进入；楼梯第一落点允许占人，并按该占用者的永久地形避让旗标挤开玩家/怪物；随后按 `restoreMonster` 规则排除机器/楼梯/生物。入层等待债等于当前 movementSpeed。坑降 6…12 clump2，护盾/无敌按既有伤害原语处理，悬浮不掷伤害骰。 |
| `Architect.c:3501–3574` | 折返按剩余倒计时反推已走距离，沿图恢复位置（`nextStep(...,true)` 倒序优先）；清 approaches/preplaced/吸收进行态及计数。真实入层时脱离不在本层的怪物 leader。JSON 解码不调用此生命周期，跨层对象图仍完整恢复。 |
| `Time.c:2130` | 跨层只通过 U10 `clearCorpseTargetOnLevelChange()` 清尸体位置；不整组删除学习/吸收载荷。 |
| `RogueMain.c:660,734–806` | 离开记录 `awaySince=absoluteTurnNumber`；新层50步，重访 `min(max(now-awaySince,0),100)` 步；在 oldSeed 回切后运行。每步历史时钟为 `max(now, remaining)-remaining`，结束恢复绝对时钟和玩家位置。环境门非正时仅加100一次。 |
| `Time.c:1590–1710` | 共用独立 `updateEnvironment()`：怪物坠落、气体两轮、晋升/记账、火、地面物品。原 web 气体在火段之后，与 CE 冲突，本轮改到晋升/火之前。玩家踩格晋升留在正常客观块；补跑不执行它。 |

补跑没有调用 `objectiveTimeBlock`、角色状态递减、营养、再生、装备充能/鉴定、刷怪 fuse、scent、waypoint 滚动刷新或玩家回合结算。地形自身引起的坠落/爆炸/休眠唤醒仍属于环境事务。缓存层过时的可见格先清除，最后重新计算视野；进层设置 `needsRender`，修复立即保存后读取时可见实体集合才补齐的问题。

本轮是普通跨梯跟随和既有环境内核的离层调度，不声称实现 CE 的 Yendor Warden 特殊跨多层追踪、完整 `updateMonsterState`/潜水簿记、所有环境目录与 DFChance 来源或玩家可玩深度扩展。既有 pending 坠层怪的生成期实化仍沿用已有入口；普通跟随没有借它伪造瞬间到达。
