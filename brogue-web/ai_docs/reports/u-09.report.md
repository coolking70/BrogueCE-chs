## 3. 执行补齐与施法者归属

- `Combat/Bolt.ts` 原15项的顺序、强度、目标和火属性逐项不变，新增9项执行身份及2项CE禁施身份，总计26项。枚举值、物品bolt配置、CE目录、怪物数据和生成池不变。
- `Monster.specificallyValidBoltTarget` 消费目录forbidden位和Q的反射回避门，LIGHTNING也不打敌方催眠者；INVISIBILITY是友方法术，CONJURATION的HALTS_BEFORE使其不受反射回避。保留一般目标遍历、bolt顺序、30%/ALWAYS短路和行动计时。选靶被拒不掷施法骰、不扣tick。
- `Game.castMonsterBolt` 继续使用原 `traceBolt/boltWorld`；命中分派处理真实受害者，CONJURATION在轨迹完成后只按实际landing召唤一次，不能在请求目标强行落刀刃。穿透LIGHTNING逐目标独立掷伤害，致死玩家后按U06终止，不套近战命中/护甲/附效。
- 玩家和怪物共用四个窄原语：`teleportBoltTarget`、`polymorphBoltTarget`、`dominateBoltTarget`、`conjureBladesAt`。传送/状态/变形分别复用W11/W9/W19；刀刃落位复用W16 `bladeSpawnLocation`，未造第二套召唤落点系统。满图保持W16已有“停止创建合法实体”边界，不造重叠或越界刀刃；不宣称完整复刻CE无空格异常行为。
- **DOMINATION成功仍调用玩家的 `becomeAllyWith`**，包含领导降级、清discord与dominated标记；玩家/无生命/无敌接触不掷支配骰。失败不转队。**CONJURATION固定isAlly/boundToPlayer/doesNotTrackLeader**，web以`leader=null + boundToPlayer`表示玩家绑定，仍不是caster领袖。
- 反射不转移吸血/死亡归属；自反射先给原caster回生命，再扣同一人的生命。POISON是状态写入，不给caster即时回血；后续毒/火/环境tick在CE以NULL攻击者调用伤害，也不追溯法术caster吸血。

## 4. 永久同步、TRANSFERENCE与TURRET专项

`Monster.ts:672` 的同步只被初始化、突变、变形调用；`afterLearning=true`是U11安装后应调用的接口，本轮仅夹具手工安装使用。它不选择尸体、不安装技能、不倒数、不扣额度、不额外掷骰。三种可学行为的永久状态通过真实客观状态tick、当前JSON快照往返、消魔后再sync均验证：仍持旗标时1000不减，消魔删旗标后不能凭同步复活。另外验证已有FIERY接收者学REFLECT_50后burning1000不减、消魔不复活；不将FIERY加入学习候选。现有web完整maxStatus和MB_SUBMERGED仍未建模，本轮不以这些缺字段为由伪造吸收存档。

吸血统一在 `engine/Combat/Combat.ts:302` 的 `CombatSystem.transferMonsterHealth`，近战/攻击几何/BE_ATTACK通过 `attack`，怪物FIRE/SPARK/DRAGONFIRE/新增LIGHTNING通过 `applyMonsterBoltHit`。已反查其余伤害出口：投掷武器的thrower类型固定Player；玩家杖、护甲反击是玩家来源；击退碰撞及环境/毒/燃烧无怪物攻击者。这些不应因学习MA_TRANSFERENCE给某只怪物补吸血。玩家戒指transference属于U15b，不混入本任务。

公式为 `trunc(min(穿盾伤害,受害者扣血前HP) × (盟友?4:9) / 10)`。护盾全挡时0；致死过量伤害不多吸；回生命没有maxHP截断；INANIMATE/INVULNERABLE拒绝。削弱只在物理攻击、原伤害>0且受害者存活时触发，盾全挡也能削弱；已有weakness的持续与层数不因消魔消失。测试同时覆盖怪物受害者、BE_ATTACK和BE_DAMAGE区别。

CE `MONST_TURRET` 是六位并集：IMMUNE_TO_WEBS、NEVER_SLEEPS、IMMOBILE、INANIMATE、ATTACKABLE_THRU_WALLS、WILL_NOT_USE_STAIRS。web目录用单个字符串保存它；本轮 `hasCEBehavior` 在已核效果门展开单个位查询，修正传送/定向状态/毒/吸血/削弱/选靶的资格。**没有全局改写hasBehavior、没有把TURRET扩写进生成数据**，所以初始化睡眠抽签等旧行为不被顺带改变。炮塔既不能成为可吸收尸体，也不能以TURRET“能力”被学会；其六个位也不在NEGATABLE_TRAITS，消魔不会让它获得移动能力。
