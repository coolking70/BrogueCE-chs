# FE-1 阶段 A：前端现状审查与设计方案

> 起点：标签 `v0.1.0`（2e45435c）。本阶段只产出文档与截图，不改代码。
> 截图脚本：`ai_docs/reports/fe-1-evidence/audit-capture.mjs`（Playwright，种子 12345，
> 平板/手机视口开启 `isMobile + hasTouch`、DPR 2）。截图文件名前缀 `A-`。

## 2. 问题清单

### 2.1 地图缩放与可读性
- **P-1（严重）** 平板与手机上每格只有 5–6px，字形（`#`、`"`、怪物字母）完全不可辨认，
  也无法准确点中某一格（见 `A-tablet-768x1024-02-game.png`、`A-phone-390x844-02-game.png`）。
  根因：`computeMapLayout` 的 uniform 模式永远把 79 列整幅塞进容器，没有"视口跟随玩家"的概念。
- **P-2** 平板竖屏把 340px 侧栏放在右侧，地图区只剩 428px 宽，而纵向有 1024px 却大半留黑
  （地图实占 157px 高）。竖屏应改为上下布局。
- **P-3** 手机竖屏地图区固定 52vh，uniform 缩放后地图只占 143px 高，其余全是黑边。
- **P-4** 无缩放/平移手段：没有捏合、拖动或缩放按钮，也无法把视口居中到玩家。
- **P-5** 桌面 1440×900 下地图 13.9px/格、可读，但上下各留约 250px 黑边——这是 uniform 模式的既定口径（P2-6），**桌面不做改动**。

### 2.2 侧栏 / 背包 / 详情遮挡
- **P-6（严重）** `AgentControls`（方向键 + 四个按钮）以 `opacity: 0.15` 绝对定位浮在右下角，
  在平板/手机上直接盖住侧栏、背包与日志（`A-phone-390x844-03-inventory.png` 中方向键叠在背包操作按钮上，
  `A-phone-land-844x390-02-game.png` 中叠在"可见生物"上）。它是给自动化代理用的"近乎隐形"控件，
  触屏玩家看不清也不知道它存在。
- **P-7** 手机竖屏侧栏占下半屏 405px，品牌标题"BROGUE JS"就占去 ~70px，行动日志只露出一行。
- **P-8** 手机横屏侧栏固定 340px，占去 40% 宽度；日志区完全被挤出可视范围。
- **P-9** 背包弹层在手机竖屏：操作按钮行 `padding-left: 3.5rem` + 不换行，四个按钮被压成竖排单字
  （"查/看/详/情"，见 `A-phone-390x844-03-inventory.png`）；手机横屏下背包弹层高度 85vh，
  只能看到两行物品，弹层内滚动但标题栏占 1/4 高度。
- **P-10** 详情面板 `min-width: 320px`，在 390 宽下几乎贴边；关闭钮仅 28×28px。
- **P-11** 发现屏/帮助在手机上已有 650px 断点改单列，可用；但帮助只列键盘按键，触屏玩家无对应说明。
- **P-12（严重）** 主菜单在手机横屏 844×390 下卡片高度超过视口、`body { overflow: hidden }`，
  标题与底部设置被裁掉且**无法滚动**（`A-phone-land-844x390-01-menu.png`）。
- **P-13** 结局面板 `min-width: 400px`，在 390 宽手机上横向溢出。
- **P-14** 录像控制条 `min-width: 300px` 居中贴底，手机竖屏会压在侧栏日志上。

### 2.3 按钮尺寸与触控
- **P-15** "菜单"钮 30px 高；背包关闭钮 32px；详情关闭钮 28px；录像按钮约 26px 高——均低于 44px 触控建议值。
- **P-16** 地图只响应 `pointerup`：触屏单击 = 鼠标左键（相邻格移动/远处自动寻路，可用），
  但**没有长按查看**（桌面靠右键 `handleInspectAt`，触屏没有右键），也没有悬停提示。
- **P-17** 没有触屏可达的搜索、休息、上下楼、投掷、发现屏、帮助入口（只有键盘）。
- **P-18** 目标选择：投掷模式下点相邻格会被当作"移动"（`pointerup` 相邻格分支先于投掷判断），
  无法对相邻怪物投掷；且投掷/法杖选目标都没有可见的"确认/取消"按钮，法杖只有文字提示（写着键盘键位）。
- **P-19** 投掷模式在引擎里没有取消路径（`isThrowing` 只在投出后清零），桌面也一样——见报告"引擎接口需求"。

### 2.4 中文字形
- **P-20** 界面字体栈 `Inter, system-ui` 与 `Fira Code, Courier New` 都不含 CJK 字形，中文走系统回退
  （macOS 苹方 / Android 思源），可以显示但与西文基线/字重不统一；`.category-title` 等处的
  `text-transform: uppercase; letter-spacing` 对中文无意义，反而拉开字距。
- **P-21** 地图字形用 `Courier New` 绘制；缩放到 5px 以下时抗锯齿后成为色块（P-1 的一部分）。
- **P-22** `ReferenceOverlay.vue` 的标题、分组名、帮助条目以 `zh ? '中文' : 'English'` 硬编码在脚本里
  （不在模板文本节点，守卫未覆盖），应迁入 `zh_CN.json`。`DetailPanel.vue` 关闭钮 `title="关闭 (Esc)"` 同理。

### 2.5 滚动与溢出
- **P-23** 全局 `body { overflow: hidden }` + `.app-layout { height: 100vh }`：移动浏览器地址栏收起/展开时 `100vh`
  大于可视高度，底部内容被裁（应使用 `100dvh`）。
- **P-24** 无 `viewport-fit=cover` / 安全区内边距，刘海屏横屏时左侧按钮会进入刘海区。
- **P-25** 双击地图会触发浏览器缩放（缺 `touch-action`），长按会弹出系统菜单/选中文本。

## 3. 设计方案

### 3.1 布局（三种模式，按容器尺寸而非 UA 判定）
| 模式 | 触发 | 结构 |
|---|---|---|
| `desktop` | 宽 ≥ 1024 且 高 ≥ 600 | 与现状完全一致：地图 + 右侧侧栏。粗指针设备额外显示可收起的触控命令栏。 |
| `portrait` | 其余且 宽 ≤ 高 | 上：紧凑状态条（深度/生命/饱食/状态）；中：地图（占满剩余）；下：最近 2–3 条消息 + 命令栏 + 方向键。侧栏整体改为右侧抽屉（"详情"按钮打开，含可见生物与完整日志）。 |
| `landscape` | 其余且 宽 > 高 | 地图全屏；左侧竖向命令栏；右下半透明方向键；顶部浮动状态条；侧栏同样进抽屉。 |

- 背包、详情、发现屏、结局、主菜单在非桌面模式下改为**底部弹层 / 全屏面板**：宽 100%、高 ≤ 100dvh、内部滚动、标题栏吸顶、关闭钮 ≥ 44px。
- 所有高度改用 `100dvh`，并加 `env(safe-area-inset-*)` 内边距。

### 3.2 地图视口
- 新增纯函数 `computeMapCamera`（`src/ui/mapCamera.ts`）：当 uniform 缩放后每格 < 12px 时切入"跟随模式"：
  每格像素 = 用户缩放级（默认按视口给出约 14–18px），视口以玩家为中心、夹在地图边界内；
  用户拖动地图可临时平移，玩家下一次移动后回到跟随。
- 桌面仍走现有 `computeMapLayout`（等比/拉伸两种模式与 P2-6 守卫不变），跟随相机只在其结果"过小"时叠加。
- 捏合缩放 + 缩放按钮（− / + / 居中），缩放级为纯 UI 状态，存 localStorage，不进存档/录像。

### 3.3 交互
- 单击地图：沿用现有 `pointerup` 分支（相邻格 → `move`，远处 → `mouse_travel`）。
- 长按（≥ 450ms、位移 < 10px）：`updateHover` + `handleInspectAt`（与桌面右键同一只读路径），不产生命令。
- 拖动：平移相机（纯显示）；双指：捏合缩放。
- 命令栏（≥ 44px 按钮）：搜索、休息、背包、投掷、拾取、上楼、下楼、自动探索、发现屏、帮助、日志抽屉、菜单。
- 方向键：3×3，中心为"休息"；全部经 `inputManager.triggerAction` → `game.handlePlayerAction`。
- 目标选择条（投掷/法杖/魔杖期间出现）：点地图只设"瞄准格"（法杖用 `move` 增量移动引擎光标——录制在内；
  投掷为 UI 高亮），再点同一格或点"确认"才提交；"取消"发 `escape`；法杖另有"下一个目标"（`cycle_target`）。
- 背包：操作按钮改为自动换行的网格、最小 44px；鉴定/附魔选物的候选行加大点击区。

### 3.4 配色 / 字体方向（阶段 D）
- 保持深色底 + 字符地图；面板统一为一套 token：`--panel-bg`、`--panel-border`、`--accent`（青）、`--gold`、`--danger`，
  圆角 10px、描边 1px、不再混用蓝紫/灰黑多套玻璃风格。
- 字体栈加入 CJK：`"Inter", "PingFang SC", "Hiragino Sans GB", "Noto Sans SC", "Microsoft YaHei", system-ui`；
  等宽栈同样补 CJK 回退；移除对中文无效的 `uppercase/letter-spacing`。
- 暗色可读性：正文不低于 `#d4d4d8` on `#0b0b0e`（对比度 > 12:1），次要文字不低于 `#a1a1aa`（> 7:1）；
  禁用态以透明度 0.45 + 虚线描边区分，而非仅靠变暗。
