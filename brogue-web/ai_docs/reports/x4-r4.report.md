## 实现

`generateItemDetail(item, strength)` 保持兼容，同时接受 `ItemDetailContext`。新增 Intro / Equipment / Arcana / Jewelry 模块，保留 `DetailInfo`。背包“查看详情”从现有公开玩家字段组装冻结的上下文；当前装备只传递已知附魔（未知按 0 假设并注明），不把 live Item 放进上下文。智慧戒指按 CE `apparentRingBonus` 取种类已知戒指的有效加成。缺少 HP、营养、携带关系或历史时省略对应段落。

Loader 的唯一行为改动是把现有 `description` 传给 11 类实例，另给 `ConsumableConfig` 补可选类型声明。Intro 从同一类别目录解析，恢复后 description 缺失的对象也可读目录；钥匙在现有无 identityId 的合同下以已知名称回查。未知五类只取 flavor 表，既不读取 true description，也不回退到真名；已知简介与新增文案通过 `detail.item.*` i18n 键。金币、流明石、护符石有独立正文。激怒卷轴预留简介键，未新增实体或权重。

`ItemKnowledge` 分开种类、实例、法杖容量、魔杖余量、符文、诅咒和探测极性门控。修正原“CE 无详情诅咒分支”的错误注释。非装备类别的符文/诅咒知识为不适用，不把这些类别伪造为可诅咒。

## 数值来源与差异边界

- 直接复用 `CombatFormulas` 的 strength/netEnchant、accuracy/damageFraction、enchantedDamage、playerDefense、武器触发率/持续/分身/推力、护甲吸收/反伤/反射；E+1 装备预测同时把力量需求降低1（最低0），不调用会改变物品且可能掷 RNG 的附魔动作。
- 法杖复用 `StaffDamage`、`Poison`、`Shielding`、`BoltTrajectory`、`Entrancement`、`Conjuration`、`ArcanaRecharge`；魔杖范围/附魔增量共用 `WAND_INITIAL_RANGES`；戒指复用 RingBonuses/Wisdom；护符全部共用 CharmModel。
- 回电显示采用当前执行规则的整数 `ringWisdomRechargeIncrement`。例如 E3 普通法杖、表观智慧+1：`floor(5000/3)/12` 截断为138回合；不把连续倍率误作实际每回合的整数充能增量，不读取剩余隐藏计时器，不抽取随机周期。
- Game 内仍为内联表达式的加速 `2+4E`、不和 `4E`、治疗 `min(100,10E)`、护甲潜行 `max(0,strengthRequired−12)`，以及 ItemUseCoordinator 的装备 `E+1/需求−1`，本次保持同一表达式。既有戒指潜行/察觉/吸血/收割等线性数值也保留原规则表达式。它们尚未实现“执行方与显示方共用一个导出函数”，需要 R6 抽取，不能据本报告称共享公式合同已全部闭合。新增用真实 `Game.applyBasicBoltEffect` 对加速/不和/治疗 E3/E4 的执行结果与详情对照。
- CE 护甲 multiplicity 在仅符文已知时会读取隐藏 E；本次坚持 B-1a，数值统一要求实例已知。负附魔 reflection 的 CE 自我偏转机制在当前 web 执行层缺失，详情按现有正净附魔反射规则显示，不声称未实现的自伤行为。

## R6 集成需求

1. 将 `Game.ts` 当前两个 `generateItemDetail(item, effectiveStrength)` 入口（键盘检视与 `handleInspectAt`）接入与背包相同的 `createItemDetailContext`。基础/知识门控正文现已共用；HP、食物利用率、戒指回电和装备比较等上下文段落，在这两个旧入口仍省略。本次不越权修改 Game。
2. 新增并持久化法杖最近三次**实际可知使用**的回合记录；由 R6 在使用成功时维护，组装 `knownStaffUses/currentTurn`。禁止从隐藏回电进度倒推；本次只有只读接口和0/1/2/3次历史分支，没有新持久状态。
3. 普通物品的发现层数若当前来源未填 `originDepth`，需由 R6 明确拾取/生成/堆叠归属并接快照；宝库品保留 ITEM_IS_KEY。当前详情只显示现存证据，不能拿当前层冒充来源层。
4. 抽取上述内联 Game/ItemUseCoordinator 公式为规则层纯函数，让两个消费者共同调用；追加真实执行 E/E+1 对照门禁。本次未修改规则或执行入口。
