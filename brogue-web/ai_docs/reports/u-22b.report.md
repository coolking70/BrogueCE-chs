# U22b：发现屏按 CE 规则显示

## CE 规则核实

本地 `../BrogueCE-master/src/brogue/IO.c:4271–4317` 的 `printDiscoveries` 逐类先累加**未鉴定**种类的 `frequency`，随后每行复制 `theTable[i].name` 并转大写。已鉴定行用白字和物品字形；未鉴定行用暗灰字，前缀仅在 `magicCharDiscoverySuffix` 返回善/恶时绘制对应符号。未鉴定且频率大于零时追加 `frequency * 100 / totalFrequency` 的整数百分比。`:4372–4407` 的发现屏只排卷轴、戒指、药水、法杖、魔杖，列布局为卷轴/戒指、药水、法杖/魔杖。真名清单不包含外观到种类的对应关系。U22 任务书关于隐藏真名的要求与源码冲突，本轮依 CE 修正。

## 改动与边界

- `Discoveries.ts` 保留 CE 表顺序，从 `ItemLoader.genScrolls/genRings/genPotions/genStaffs/genWands` 取当前实际生成池；缺失种类不显示匿名行。所有行显示大写真名。未鉴定百分比按同类未鉴定且在池内的频率总和计算，零频率不显示。
- `ReferenceOverlay.vue` 移除已知/未知计数、描述和原始频率；用三列独立堆叠复现 CE 分组，窄屏单列。已鉴定白色并有类别字形，未鉴定暗灰色并保留已揭示善/恶符号。
- `ItemKnowledge.ts`、背包详情、鉴定/极性/外观状态及生成路径未改。发现屏展示真名不改变外观映射的知识边界。

## 黄金值与缺失清单

`Discoveries.test.ts` 固定五组池内数量为 13/6/15/12/9。全未鉴定时六枚戒指各为 `floor(1*100/6)=16%`；鉴定一枚后其余各为 `20%`。卷轴鉴定卷轴频率 30、同类分母 143，显示 `20%`；频率为零的附魔卷轴不显示百分比。测试还验证未鉴定生命药水显示真名，绰号不替换真名；原详情实例附魔隐私测试继续通过。
