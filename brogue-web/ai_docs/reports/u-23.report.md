# U23 地图记忆与魔法测绘执行报告

## 规格与 CE 核对

依据 `x-0-survey.report.md` §3.1 K18、§4.4 U23。CE `Movement.c:2564-2569,2625-2651` 在视野退出时保存地形、地形旗标和机械旗标；`IO.c:1130-1141,1282-1304,1337-1357` 恢复稳定的字形/前景/背景及物品记忆。`Items.c:7729-7737,7945-7971` 的测绘先发现秘密格，再测绘未发现且非花岗岩的格，仅取 dungeon/liquid 两层，并标记无陷阱格。测绘不等于亲眼发现。

## 实施

- `Cell` 新增历史地形、四层历史、外观、物品类别/展示快照、地形/机械旗标、`isMagicMapped`、`knownTrapFree`；`updateVision` 只在可见时刷新这些历史值。不可见后的世界改动不改历史。
- `Appearance` 在不可见时读 `rememberedAppearance`/`rememberedLayers`。画布只绘制历史物品，当前不可见物品不会以旧的 `hasMemory` 分支漏出。探魔符号仍按 CE 的独立已探测信息显示。
- 测绘卷轴保留 `isExplored=false`，跳过未发现花岗岩，记录 dungeon/liquid 层和两层旗标；可落地的秘密门、麻痹气陷阱按目录的发现目标显形。无陷阱格登记 `knownTrapFree`。卷轴路径没有调用实质 RNG。
- hover 的地形、物品、标记读取已知历史；自动探索的目标、拾取判断和寻路使用已知层/历史物品。实际迈步仍执行真实碰撞。
- U03 的 `CELL_FIELDS`、读档后视野重建恢复及快照验证已登记全部新增字段。缺少新字段的旧格式快照被拒绝，避免读取未定义的历史层。

## 已知边界

- CE 的一些秘密地形发现目标在当前 web `DungeonFeatureCatalog` 中仍是 `tile: null`（如陷阱门、毒气/喷火陷阱、隐藏墙杆及若干机器喷口）。本轮只显露已有真实 tile 的目标；这些缺失目标保持原状，不能伪装成已经完整实现。对应目录条目需在相关地形实装轮补齐。
- `MB_SUBMERGED` 的水下生物簿记未新增；任务书允许独立验收，本轮未改生物视觉与观察载体。
