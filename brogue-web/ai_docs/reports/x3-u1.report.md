## 2. 拒绝、录像与 RNG

沿用 U27 的命令合同：`executeCommand` 记录输入和 `commandDecisions`，**拒绝不会记录成已执行的移动/攻击**。拒绝后的检查点与操作前相同，位置、HP、状态、回合、时钟、实体、武器附魔和双 RNG 流均不变；confirm 决策为 `[false]`，岩浆硬拒绝为 `[]`。保留这个无执行效果的输入事件是既有录像机制的必要部分，U27 原守卫也要求拒绝/接受分别记录 `[false]`/`[true]`。没有删除输入事件或改变录像协议。

回放/seek 直接消费 `commandDecisions`，不调用 UI；自动行进先停止的状态变更在回放执行相同路径。新测试对同一确定性房间，在正常 seed 初始化后安装同一夹具，真实执行命令、导出、loadReplay、逐步回放和 seek，对比最终状态与检查点；不替换动作、确认消费者或 RNG。动画自动步骤也检查最终检查点与零 OOS。

新增判断只读已有状态，不调用 RNG；本轮未修改既有混乱/幻觉选方向的 RNG 语义。
