# W-16：召唤刀刃

基准 `bc88cbf`，2026-09-23。规格取 W-0 报告 W-16 行（实际在 §2.4 效果表，任务书称 §2.3）。CE 依据全部为仓库 `BrogueCE-master`，没有套用其他版本。

已实现真实 `spectral_blade` 实体、落点择格、玩家绑定与不跟随、主动攻击、101 tick 首行动等待、消魔及快照。autoID 由“仅表现 false”改为**至少成功注册一个实体才 true**。没有新增物品/怪物种类、修改 frequency 或生成算法。

## 1. 公式和落格

CE `PowerTables.c:54` 原函数：`((int) (enchant * 3 / 2 / FP_FACTOR))`，`FP_FACTOR=65536`。本轮 `scripts/w16-ce-golden.mjs` 提取原行、clang 编译后输出 E=0…20、步进0.25的81个黄金值；测试读取编译产物而非用JS同公式当oracle。E2=3、E3=4、E8=12。证据：[原函数程序](w-16-evidence/ce-blade-count.c)、[黄金值](w-16-evidence/ce-blade-count.txt)。正常法杖E为整数；helper保留定点截断，不把奇数E向上取整。

`Items.c:5494-5514` 在 **detonateBolt** 而非每次命中时召唤。web沿W-3轨迹取最终 `landingPos`，包括遇怪前停、贴脸首格接触、墙前停和空路径。CONJURATION从逐命中分派排除，完整旅行结束后只落地一次。使用实例 enchantment，不使用 charges、maxCharges 或配置旧 magnitude。

`Grid.c:287-360` 的择格规则：

- 原点合格直接返回，不抽择格随机数。
- 路径阻挡为 `T_DIVIDES_LEVEL & avoidedFlags & ~T_SPONTANEOUSLY_IGNITES` 加 `HAS_PLAYER`；刀刃飞行后实际地形阻挡为不可通行。八向等权距离，两个侧格任一有 `T_OBSTRUCTS_DIAGONAL_MOVEMENT` 时不可斜穿。
- 落点禁止 `avoidedFlags & ~T_SPONTANEOUSLY_IGNITES` 以及玩家、活动怪物、楼梯。飞行+无生命刀刃允许水、熔岩、深渊、陷阱、蛛网、毒/麻痹气；禁止墙/水晶墙/力场、火、爆炸地形、圣徽。自燃硫矿仅在**生成落格**获得豁免。
- 在最小正距离的合格格中，按x-major候选均匀随机；前一把注册后，下一把重新查占格，不重叠。
- 无可达合格格才回退几何邻环；全图无位置时不构造实体，不制造越界坐标，全部失败不autoID，部分成功按真实数量返回。
- 休眠怪不占 `HAS_MONSTER`，没有照搬W-11更强的“排休眠怪”安置策略。机器格/地面物品不被无依据地排除。

专用 `Combat/Conjuration.ts` 没有改P4-2 `findNearbySpawnSpot` 或W-11安置helper。CE在绝对无位置/E0这种退化场景仍在循环后无条件autoID；本轮按照用户更强的“真实召唤才可识别”要求，以成功注册数为准。

## 2. 绑定、不追踪、首行动与战斗

`Items.c:5500-5504`：`MB_FOLLOWER | MB_BOUND_TO_LEADER | MB_DOES_NOT_TRACK_LEADER`、leader=player、state=ALLY、清JUST_SUMMONED、`ticksUntilTurn=info.attackSpeed+1`。

web沿已有俘虏释放约定，以 `isAlly=true + leader=null` 表示玩家随从；另存 `boundToPlayer` 和 `doesNotTrackLeader`。不把player塞进P4-2的Monster leader类型，也不改变敌方countMinions的身份比较。刀刃数据来自既有目录：HP1、accuracy150、damage1d1、移动50、攻击100、飞行/无生命/从不入睡/消魔即死/不走楼梯/免蛛网；无突变。

**“不追踪”不是不追敌人，更不是跟随玩家。** `Rogue.h:2159` 明确“不跟随leader”；`Monsters.c:3163` 此标记还豁免玩家距离牵绳；`:3231-3235` 没敌人时 `monsterMillAbout(monst,30)`。实现为依据刀刃自身的地形视线选择敌人（不要求玩家FOV），使用W-3 `BOLT_NONE`射线偏移选线，再按CE `moveMonsterPassivelyTowards`方向优先/备选移动；无敌人时30%随机邻移。实体不可穿墙、力场或斜角，不进入楼梯；刀刃从蛛网离开不再误走旧50%卡网占位逻辑。

`Monsters.c:3005` 的HP1盟友不会逃跑；本轮刀刃不因远离玩家逃跑/返回。近战用现有Combat命中、伤害与分裂出口，不硬编码扣HP。普通命中1；睡眠目标仍可能按既有Combat吃偷袭倍率。

首等待是 **101客观tick**，不是“一律跳过一次动作”：正常100或加速50的施法动作内不行动；玩家200的慢动作内，101、151时可以行动。之后移动50/攻击100。测试分别钉住50/100/200推进及实际近战HP。

发现并补齐了新刀刃必需的两个旧AI缺口：

1. `Monsters.c:3449-3464、3575起`：醒着的敌人可近战邻近盟友。仅对**本轮绑定玩家的刀刃**新增还击入口；HUNTING优先可攻击的相邻玩家，仍经既有几何/Combat攻击，睡眠/麻痹/俘虏/不可移动的早退保留。
2. `Monsters.c` 的NEGATION选敌规则包含消魔即死生物。现有“仅增益/盾”门增补绑定玩家的刀刃；dar priestess/pixie可直接消魔刀刃。其它物种完整消魔资格仍归W-23。

## 3. “寿命到期清理”线索驳回与真实死亡

**本仓库CE conjuration刀刃没有寿命。** `generateMonster` calloc清零，`initializeStatus`/目录没有设LIFESPAN，`Items.c:5494-5514`也未设它。设置 `STATUS_LIFESPAN_REMAINING` 的 `Items.c:7455` 是**guardian护符**，不能搬到刀刃上。

任务的另一假设也不符合源码：`Monsters.c:1902-1915` 通用寿命到期实际调用 `killCreature(monst,false)`；无掉落/DF的行政移除是 `Combat.c:1930-2050` 的 `administrativeDeath=true`，不是这个寿命分支。**本轮不实现不存在的刀刃计时器，也不改通用寿命/死亡机制。** 因此不存在“刀刃到期误触发W-10死亡结算”的路径。

证据不只看字段：200次客观状态递减及死亡扫描后，原刀刃仍是网格上的同一实体，HP1，`die`/loot调用0，kills不变、地面物品0，额外挂的MA_DF_ON_DEATH也不触发。绑定不是到期计数，`Time.c:2561-2564` 的失去leader清理还明确排除了ALLY；不能把玩家下楼解释为刀刃即刻死亡。

真正受伤/消魔死亡沿原链：`negateCreatureMagic → takeDamage(hp,true) → die → triggerDeathFeatures/removeDeadMonsters`，护盾不能挡消魔。测试断言真实实体HP0、die一次、清扫后查不到实体、重复清扫无重复掉落。刀刃目录无死亡DF/携物旗标；CE `generateMonster(MK_SPECTRAL_BLADE,true,false)` **第二参数其实是itemPossible=true、第三参数是mutationPossible=false**，但`Monsters.c:133-148`无CARRY_ITEM旗标使itemChance=0。web明确使本轮召唤实例的随机金币/物品概率为0，不按JSON旧0.05留形值给新刀刃造战利品。未新增经验系统。

W-10所有死亡结算入口及W-15伤害规则未改；最终boundary证据钉住这些方法正文。

## 5. 跨层、快照与旧档

CE `Globals.c:1137-1138` 刀刃有 `MONST_WILL_NOT_USE_STAIRS`；`RogueMain.c:594-609` 排除跟随换层。web现有层缓存本就将怪物留在原层：下楼后新层无刀刃、原层对象仍存活；返回得到同一对象及关系，不销毁、不掉落、不触发死亡DF。测试用两层真实Grid/环境/缓存执行generateDepth往返，未伪造删除回调。

当前层JSON增加**仅刀刃使用**的可选 `spectralBlade` tag，含isAlly/boundToPlayer/doesNotTrackLeader/ticksUntilTurn。tag明确物种，避免中文name派生错误typeId；恢复时用既有刀刃目录还原速度、永久飞行/蛛网免疫/消魔即死等。活动怪、休眠怪、测试房基线/恢复都接入同一payload。新tag恢复不抽RNG，快照保留首等待的剩余1tick，不重新让刀刃睡眠或立即行动。

旧档无tag：不猜“所有spectral blade都是玩家盟友”，保留旧恢复语义与默认false关系；旧版本本来不能从法杖召出刀刃，既有horde刀刃不能因迁移被转队。tag有而ticks非法/缺省时取101，关系缺省false。新档的horde刀刃也带物种tag，恢复其目录特性和原false关系；未扩张其它怪物的通用序列化字段。

**既有全局存档边界仍在：GameSnapshot只存当前层，不保存整个levels缓存；离开一层后在另一层保存再重载，旧层整体缓存会丢失。** 本轮没有把刀刃伪装为跨层跟随以掩盖该问题，也没有重构全游戏多层存档。CE通过完整回放持久化各层，web这项既有差异不等于已对齐；本轮验收是内存跨层留层、当前层/休眠/测试房快照的真实刀刃往返。
