# V-2b-8 报告：autoGenerator MT_* 接线轮

## 1. `bp` 形参与 CE 依据

CE `Architect.c:984-991` 的签名把 `bp` 放在第一形参；`:1013` 以 `((signed short) bp) <= 0` 计算 `chooseBP`，`:1028-1061` 只在 `chooseBP` 时做深度/旗标/频率抽签。web 的 `BlueprintEngine.buildAMachine` 现公开接收 `requestedBp`：`<=0` 延续原抽签，正值按 `ceBlueprintId` 精确选择，且零频率蓝图合法。

“强制指定不过 reward 配额”的 CE 证据是：配额及 `BP_REWARD` 抽签只在 `addMachines` 的 `Architect.c:1757-1775`；护符强制调用在 `:1750`，autoGenerator 强制调用在 `:1848`，两者均直接调用 `buildAMachine(MT_*, ..., 0, ...)`，不经过 `rewardRoomsGenerated`。web 同样只由 `buildMachines()` 核销 reward 配额，随后 Architect 的 autoGenerator 回调直接强制建造并追加结果。

## 2. MT_* 接线

CE `runAutogenerators` 在 `Architect.c:1780-1860`，机器调用点为 `:1848`。web 在 `AutoGenerator.runAutogenerators` 增加机器建造回调；`Architect.generateLevel` 复用同一个 `BlueprintEngine`，将成功结果（含子机器）并入 `machineResults`。接通 CE 表中本轮有蓝图载体的行：index 29/39/40/41/42/43/47，即 MT 61/58/59/60/63/64/71。

授权反驳：任务书把 62 Camp 也称为 autoGenerator 强制建造，但 CE 的 `autoGeneratorCatalog_Brogue`（`GlobalsBrogue.c:114-170`）没有 MT_CAMP_AREA；唯一相关引用是 horde 表的机器归属（例如 `:761/:778`），不是 `runAutogenerators` 建造请求。因此 Camp 数据已忠实落地，但生产实测必为 0；没有虚构 CE 表行来“凑八条”。

## 3. 地形与 DF（含闭包）

- 地形：新增 `BLOODFLOWER_STALK`、`HAVEN_BEDROLL`；`BONES` 已由 V-2b-6 存在；`SACRED_GLYPH` 已存在，本轮补 `TERRAIN_MAP`。目录字段来自 `Globals.c:464/479/513/517`。
- DF 起点：`DF_BLOODFLOWER_PODS_GROW_INITIAL`、`DF_DEEP_WATER_POOL`、`DF_HAY`、`DF_JUNK`、`DF_REMNANT`、`DF_URINE`。
- 闭包：pods-initial → `DF_BLOODFLOWER_PODS_GROW`；deep-water → `DF_SHALLOW_WATER_POOL`；remnant → `DF_REMNANT_ASH`。加起点共 9 条，`c_4b` E2 的闭包规模由 90 更新为 99，无悬空 subsequentDF。
- CE 纯装饰 tile 在本轮授权的四地形之外，故 HAY/JUNK/URINE/BURNED_CARPET/BLOODFLOWER_POD 采用现有同层载体别名；CE 名、层、概率、旗标和链仍完整登记，未引入明确禁止的 RUBBLE 新地形。

样本：seed `3/777/424242` × D1–26，共 78 层，走真实 `Architect.generateLevel`，只计 `machineResults` 中 `ce_*`，因此能区分“JSON 有数据”和“生成期真的建成”。结果：

| CE id | 蓝图 | 台数 |
|---:|---|---:|
| 58 | Bloodwort | 0 |
| 59 | Shrine | 3 |
| 60 | Idyll | 2 |
| 61 | Swamp | 17 |
| 62 | Camp | 0（CE 无 autoGenerator 行） |
| 63 | Remnant | 7 |

58/71 的零值不是“只落数据”：测试首先钉死七个真实 MT 行已 wired，再由生产计数断言至少有 thematic 机器实际建成。两条在此样本中因 CE 概率低、web 门位/房间选址失败未成；若实现退回“数据落了但没建”，总台数断言和生产 `machineResults` 来源断言会翻红。
