## 逐药水矩阵

表中「共通」＝饮用成功自动鉴定种类、耗瓶并结束玩家回合；碎裂的七种功能药水自动鉴定，其他药水无害且不鉴定，唯幻觉药水已被探魔照过或善意种类全知时鉴定。投进坠层格且未撞实体时瓶子不碎。所有固定范围 `{N,N,0}` 的 `randClump` 不消耗骰。

## 修正与闭包决定

- `Game.ts`：生命上限/panacea、混乱气体、幻觉/隐身/悬浮/心灵感应/速度持续期、速度清迟缓、火免 maxStatus、黑暗饮用入口；取消仍在效果和耗时前处理。
- `Creature.ts`：`maxStatus` 类型扩至已有 `StatusId`，承载上述 CE 最大持续期；不增存档格式。`ItemLoader.ts` 补黑暗的 CE 身份与恶意极性。`consumables.json` 新增黑暗种类但排除生成；生命描述修正。中文消息/名字补齐，旧 `potion.heal_full` 移至 `zh_CN.legacy.json`。
- 投掷的既有五种功能分支、无害药水/幻觉鉴定特例、未碎裂落地与无效目标取消保持原执行链。新增黑暗瓶可手动取得，但其投掷目前仍按无害瓶处理；因此暂不回池。
- `DF_LICHEN_PLANTED` 与 `DF_DARKNESS_POTION` 均未在 web DF 目录提供完整铺装、扩散、地形接触/后继副作用。CE 的 lichen 是地衣地形及中毒接触，**不是气体**；原 web 日志称绿色毒气的历史注释属错误前提。U17 未提供完整链前，地衣不回池、不重采生成基线，也没有独立回池提交。本轮未提交 git。
- 生成流硬约束：新增黑暗目录项设 `excludeFromGeneration`；没有改旧抽取、频率、物品数量或生成基线。交互期状态改变可间接影响以后共享 RNG 路径，不能宣称所有未来局面逐位相同。
