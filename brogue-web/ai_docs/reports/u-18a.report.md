## 1. 判据基础与容易混淆的例外

四层必须 OR：DUNGEON、LIQUID、GAS、SURFACE，实际枚举顺序 GAS 在 SURFACE 前。`cell.terrain` 仅是绘制优先级投影，不能替代旗标并集。定义：

| 缩写 | 精确定义（C/Rogue.h:1924–1956） |
|---|---|
| P / V / D | `T_OBSTRUCTS_PASSABILITY` / `T_OBSTRUCTS_VISION` / `T_OBSTRUCTS_DIAGONAL_MOVEMENT` |
| SC | P ∪ V ∪ AUTO_DESCENT ∪ LAVA_INSTA_DEATH ∪ IS_DEEP_WATER ∪ SPONTANEOUSLY_IGNITES |
| PB | P ∪ AUTO_DESCENT ∪ IS_DF_TRAP ∪ LAVA_INSTA_DEATH ∪ IS_DEEP_WATER ∪ IS_FIRE ∪ SPONTANEOUSLY_IGNITES |
| DL | P ∪ AUTO_DESCENT ∪ IS_DF_TRAP ∪ LAVA_INSTA_DEATH ∪ IS_DEEP_WATER；**没有火/硫矿** |
| secretPass | `!P \|\| (TM_IS_SECRET && !(discoveredTerrainFlagsAtLoc & P))`，C/Monsters.c:3672–3675 |
| discovered flags | C/Monsters.c:1259–1311：只遍历带 TM_IS_SECRET 的层，把其 discoverType 的**直接 DF tile**旗标 OR；不执行 DF、不递归 subsequentDF、不并入非秘密层、不读 isExplored/isDiscovered |
| O / F | CE cost：OBSTRUCTION=-2、FORBIDDEN=-1；距离不可达=30000，不可混用 |

因此密门叠透明阻障时，`secretPass` 仍可能为真，这是 CE 这个查询的字面语义，**不能作为位移提交的物理安全判据**。generic cost 随后仍查 PB 的非 P 部分；`calculateDistances(canUseSecretDoors=true)` 则在 secret 分支直接返回 1，连这两张图也不能合并。

`discoveredTerrainFlagsOfCell` 放在既有 DF 查询模块，直接读取目录。缺载体的发现后继只补只读旗标事实：WALL_LEVER=P 的全阻挡组合，TRAP_DOOR=AUTO_DESCENT，GAS_TRAP_POISON/FLAMETHROWER=IS_DF_TRAP，三种喷口后继=0（C/Globals.c:348、378、380、383、388、396、399）。DF 的 `tile:null`、缺口名单、执行失败机制均未改变。
