## 4. 教训（已连续三十轮验证）

闭包走四条边；退池留形 = 加引擎过滤不改数据；覆盖门换样本不改期望；
**「建成 0 台」≠「RNG 足迹为 0」**；驳回给登记位置并区分仍有效/已过期；
**代码事实为真 ≠ 它是本次失败的成因**；CE 里"看起来不一致"的数值先查是不是承重的；
**验收方写的 CE 事实可能是错的，一律自行核实**；
**撞上守卫时改代码，不改守卫、不绕扫描器**；
**复用前轮原语发现不够通用就如实登记前轮缺口**；
**前轮的留痕登记可能正是为你预约的**，动手前 grep 相关注释；
**照搬上一轮的做法前，先确认 CE 在这里是不是也这么做**；
**公式有定点/舍入细节时，编译 CE 原函数取黄金值**；
**自己 W-0 的规格也可能写得不准**；**注释写的是意图，执行路径里可能有例外**；
**"看起来不重要"的 CE 判定位置可能是关键**；**C 的按值复制在 JS 里是浅拷贝**；
**"解状态"不是一个动作，是逐项规则**；**做不到忠实时，缩小范围并明列**；
📌 **"是否有效"与"做了什么"是两个函数时，别用一个推出另一个**。
