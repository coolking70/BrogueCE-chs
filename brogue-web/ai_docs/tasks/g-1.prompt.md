### 量纲：F-0 的建议是直接迁 CE 的 unsigned volume，**不要保 0-100 近似**

理由（F-0 §2.4 / §5.4）：随机舍入、体积守恒、>3 压制在 0-100 上全都会失真。
`addGas` 的既有调用点按 CE 的 DF `startProbability` 对照表（F-0 §3.3）一次折算。
**你可以反驳这个建议，但要给出论证。**

### P1-45 幽灵气

`Game.ts:2872` 的 `creeping_death` 药水写的是 `addGas(x, y, 1, 100)`——
字面量 `1` 就是 `GasType.FIRE`，旁边 `// Will add actual caustic gas later` 是自认的占位。
喷出一团**不渲染、无效果、却占格扩散并挡住真气体**的东西。
`creeping_death` 本身是 web 自创内容（**D2：保留代码但退出实际游戏**），按 D2 处置。
