## ★ 本轮的三个风险点

1. **`CHASM`（深渊）与坠落子系统**：CE 的深渊会让生物掉到下一层
   （`T_AUTO_DESCENT`）。web **没有坠落子系统**（路线图 P1-22，已并入 Phase C 但
   尚未实现）。若实现 CHASM 而没有坠落，玩家踩上去会发生什么？
   **请先查明 web 当前对 CHASM 地形的处理，再决定**：
   - 要么本轮不产生 CHASM（把 `rand` 的取值域收窄并**显式登记**），
   - 要么产生但让它暂时等价于不可通行，**并写留痕测试记录这个偏差**。
   **不要默默让玩家踩上去没反应。**

2. **`LAVA` 是即死地形**（P1-28 已确认豁免条件：悬浮 / 火焰免疫 / `MONST_INVULNERABLE`）。
   新增岩浆湖会让即死地形大量出现。**必须验证 P1-33 建立的"坏层为 0"不退化**
   ——岩浆在 `canMoveTo` 里**不被排除**（P1-25），所以它不会造成"不可达"，
   但会造成"走过去就死"。请在报告里说明这个区别，并实测坏层数仍为 0。

3. **`INERT_BRIMSTONE`（硫矿）**：CE 里它可被点燃、会爆炸。web 若无对应机制，
   **同第 1 点处理**：要么不产生，要么产生但显式登记其行为缺失。
