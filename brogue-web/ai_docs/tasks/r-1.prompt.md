## 1. 为什么有这一轮

渲染逻辑**全部内联在 `src/components/GameCanvas.vue`（769 行）里**，
**没有任何「给定格子 → 字形/颜色」的纯函数缝**。

后果：UI/渲染欠账已经积了六条（裸键名、EMBERS/ASH/PLAIN_FIRE 无渲染、
燃烧在怪物身上无视觉、`onConfirmRequest` 未接线、探魔地面符号、C-7 的光照渲染），
但**没有一条能写出"能被某个具体错误实现打红"的断言** ——
按本项目的测试标准，那样的轮次只会产出一堆无法证伪的断言。

**所以先做这一轮纯重构，之后 UI 轮才有落点。**

## 2. 本轮性质：**结构先行，行为逐位不变**

这是本项目的既有模式（C-4a-0 用过）：**只搬结构、不改行为**。

- **不新增、不修改任何视觉效果**。颜色值、字形、优先级、可见/记忆态的处理
  **全部逐字搬运**，不许"顺手优化"、不许"统一风格"、不许补缺失的渲染。
- 六条 UI 欠账**一条都不修**（它们归下一轮 UI-1）。
  你在重构中一定会看到"这里明显少了 EMBERS 的分支"——**登记，不要补**。
- 判据：重构前后**渲染输出必须完全一致**。

## 3. 要抽出什么

现状（自己核对）：

- `GameCanvas.vue:126` `getTerrainVisual(terrain, isVisible)` → `{char, color, bgColor}`
  —— **已经是纯函数**，只是被关在 SFC 里、未导出；
- `GameCanvas.vue:341` 起的 `render()`（约 220 行）里混着**外观决策**与 **Pixi 绘制**；
- `GameCanvas.vue:447` 的 `placeEntity(text, color, x, y, isInteractive)`
  是**绘制原语**，但"该画什么字符、什么颜色"的决策在 `render()` 里。

**新建 `src/engine/UI/Appearance.ts`**（若你认为别的路径更合理，说明理由），
把**决策**搬过去，`GameCanvas.vue` 只留**绘制**：

1. `terrainAppearance(terrain, isVisible)` —— 由 `getTerrainVisual` 原样迁入；
2. `cellAppearance(cell, ctx)` —— 一个格子最终画成什么（地形 + 可见/记忆/未探索态）；
3. `entityAppearance(entity, ctx)` —— 怪物/物品/玩家画成什么字符与颜色。

`ctx` 是一个**显式的输入对象**（可见性、光照、玩家状态、幻觉、心灵感应……
按现状实际用到的输入决定），**不要让纯函数去读全局 `game`**。
这条是本轮的核心价值：**把隐式依赖变成显式参数**，否则测不了。

## 6. 测试要求

### 6.1 特征化测试（characterization tests）

这是重构轮的标准做法：**先把现状钉下来，再重构**。

对 `terrainAppearance`：**遍历 `TerrainType` 的每一个成员**（当前 47 个），
在 `isVisible` 为 true/false 两种情况下，把 `{char, color, bgColor}`
**全部钉成穷举表**。这张表就是"行为逐位不变"的证据。

⚠️ 注意：这类穷举表正是本项目「漏授权形态①」的常客——
**你自己新建的表，将来新增地形时会撞红**，请在表旁写清这一点。

对 `cellAppearance` / `entityAppearance`：至少覆盖
可见 / 记忆（已探索未可见）/ 未探索三态，以及怪物、物品、玩家各一例。

### 6.2 结构守卫（本轮的关键产出）

写一条**扫描器断言**：`GameCanvas.vue` 里**不再出现外观决策**。
建议判据（你可以给出更好的）：该文件内不再出现
**颜色字面量**（`#rrggbb` / `0x......`）与**字形字面量**的 switch 分支。

这条守卫的作用是**防止外观决策日后又漏回 SFC 里** ——
没有它，这轮重构会在三轮内被侵蚀掉。
**注意给出合理的豁免**（例如 Pixi 的背景色常量、UI 边框色），
豁免项要逐条写明理由，不要笼统放行。

### 6.3 对抗性测试与反向验证（强制）

至少三条，且**每条都必须真的能被某个具体的错误实现打红**。建议：

- ① 把某个地形的 `bgColor` 改掉 → 穷举表必须红；
- ② 把"记忆态"的变暗处理去掉 → 三态断言必须红；
- ③ 往 `GameCanvas.vue` 里塞一个颜色字面量 switch → 结构守卫必须红。

每条：**真的改坏 → 跑 → 贴真实失败输出 → 还原 →
`grep -rn "REVERT-ME" src/` = 0**。只写"我验证过了"判不合格。
