## 二、要测绘什么

### 1. `isBurning` 的 33 处引用：**每一处在问什么**

逐处列出（文件:行号 + 该处的语义），并归类：
- 哪些其实在问"这格是不是火地形"（CE 里等价于 `T_IS_FIRE`）；
- 哪些在问"这个生物/物品是不是着火了"（CE 里是 creature/item 的状态，不是地形）；

**这张表是 F-1 的直接输入**：F-1 要把 `isBurning` 从"并列的事实来源"
改成"派生自地形"，而派生得对不对，全看这 33 处各自在问什么。

### 2. `Gas.ts`（288 行）逐功能对照 CE

`GasType` 六值（NONE/FIRE/POISON/CONFUSION/STEAM/CREEPING_DEATH）+ `density` 0-100。
逐个回答：
- 它在 CE 里的对应物是什么（哪个 tile / 哪条 DF）？
- **`GasType.FIRE` 已知是死枚举**（交接文档记载，请复核是否仍然成立）；
- 扩散算法与 CE 的 `updateVolumetricMedia`（`Time.c` 附近 1383）差在哪？
  **注意 CE 每回合调用它两次**（`Time.c:1615-1616`）——查明为什么，web 是几次。
- `density` 0-100 与 CE 的 `pmap.volume` 量纲/上限是否可对齐？

### 3. CE 侧的清单

- 带 `T_IS_FIRE` 的地形（我数到 10 种，**请自己核实数目与名单**）：
  各自的 `fireType` / `promoteChance` / `chanceToIgnite` / 归属层；
- DF 目录里写入 GAS 层的条目（我数到 24 条，**同样请核实**）：
  各自的 tile、startProbability、probabilityDecrement；
- `exposeTileToFire` / `updateFires`（或等价函数）的机制要点。

### 4. ★ 行为基线测量（F-1 "逐位不变"门禁的依据）

F-1 的门禁将是"行为逐位不变"，所以**必须先有可比对的数字**。请实测并报出：
- 真实关卡、多种子、N 回合：点火事件数、燃烧格数随回合的曲线、
  火焰自然熄灭的平均回合数；
- 各 `GasType` 的产生次数、峰值密度、扩散半径、消散回合数；
- 玩家/怪物因火与气体受到的伤害与状态事件计数；
- **同种子决定性复核**（同操作序列两遍，逐回合火与气体状态全等）。

口径请自己定并写清楚，但必须**可复跑**——F-1 要拿同一套口径复测。
