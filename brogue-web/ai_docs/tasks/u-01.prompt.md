## 2. 核心要求：枚举，不是补 K02 点名的几个字段

K02 点名的是探针样本。⇒ **对 Item、Monster（含 Creature 基类）、Player 的每个实例字段逐项分类**：

| 类/字段 | 当前是否入档 | 应入档 / 由目录或其他字段可确定派生 / 运行期缓存可重建 / 不属于存档 | 依据（CE 字段或 web 消费者） |

- "可派生"要写清从什么派生，并有测试证明派生结果与存前一致
- 引用型字段（leader、carriedItem、carriedMonster、machineHome 等）按 ID 往返，关系恢复要在
  所有实体建完后进行（W-20 已有同类做法，请核实复用）
- 已有特例快照（变形 snapshotForm、克隆 cloneState、mutation 等）与普通对象**统一到一个合同**，
  还是保留特例——说明取舍；不能让普通对象继续比特例少存

建议：新增一个**字段覆盖守卫**（类似 W-20 的容器审计）：实体上新增字段若未在分类表登记就打红，
防止以后再漏。
