## 2. 背景

web 有一个自创的蓝图物品类别 `_random_good_`（`Game.ts:885` 起）：
`rng.randRange(0, 5)` 六选一，其中 roll 4 **直投附魔卷轴**。
`src/data/blueprints.json` 有 **11 处**引用：

```
vestibule_locked      depth[2,26]     key_fire_trap    depth[5,15]
vestibule_flammable   depth[3,12]     key_flood_trap   depth[4,12]
vestibule_guardian    depth[6,20]     key_poison_gas   depth[5,18]
vestibule_pit_traps   depth[4,15]     key_web_room     depth[4,14]
                                      key_lava_moat    depth[8,20]
                                      key_boss         depth[10,26]
area_shrine           depth[4,15]
```

**CE 全源码没有 `_random_good_` 这个概念。** CE 的做法是
**逐蓝图指定类别掩码**，实测 CE 用过的组合包括
`(WEAPON|ARMOR|WAND)`、`(STAFF|RING|CHARM)`、`(POTION|SCROLL|WEAPON|ARMOR|RING)`、
`(WEAPON)`、`(ARMOR)`、`(RING)`、`(CHARM)`、`(SCROLL)`、`(POTION)` 等，
另有带 `MF_ALTERNATIVE` 的「二选一保底大奖」（基座上的
`SCROLL_ENCHANTING` / `POTION_LIFE`）。

用户已裁决：**还原 CE 的逻辑结构**，不接受"只把抽取改成加权"这类保留自创入口的做法。
