## ★ CE 是怎么做到不切断关卡的（验收方已核实，这是本轮的关键）

**CE 的机器是有意放在割点后面的，门就开在割点上。**

1. `analyzeMap(true)`（Architect.c:192-340）除了 IN_LOOP 还算一张 **`chokeMap`**。
   原文注释（Architect.c:275-280）：
   > The chokepoint map is a number for each passable tile. If the tile is a chokepoint,
   > then the number indicates the number of tiles that would be rendered unreachable
   > if the chokepoint were blocked. If the tile is not a chokepoint, then the number
   > indicates the number of tiles that would be rendered unreachable if the nearest
   > exit chokepoint were blocked.

2. 机器选址（Architect.c:1080-1095）：
```c
analyzeMap(true);                       // 确保 chokeMap 是最新的
for 每格:
    if ((pmap[i][j].flags & IS_GATE_SITE)
        && !(pmap[i][j].flags & IS_IN_MACHINE)
        && chokeMap[i][j] >= blueprintCatalog[bp].roomSize[0]
        && chokeMap[i][j] <= blueprintCatalog[bp].roomSize[1]) {
        p->gateCandidates[totalFreq++] = (pos){i, j};    // 只有闸门位才是候选
    }
```
   即：**只挑"堵住之后被封的区域大小落在该蓝图 roomSize 区间内"的割点当门**。

3. 内部扩展（Architect.c:417-421）：
```c
if (!interior[newX][newY]
    && chokeMap[newX][newY] <= chokeMap[startX][startY]   // 只往"更深"的方向长
    && !(pmap[newX][newY].flags & IS_IN_MACHINE)) { ... }
```

**结果**：机器内部恰好是"某个割点后面那块死角"，锁上门只封死这个宝库，
**不会切断关卡其余部分**——这正是设计意图（门后是宝库，不是去路）。
