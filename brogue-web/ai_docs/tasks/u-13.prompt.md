## 1. 线索（**全部请自行核实**，读到执行路径）

  等分支、之后的特殊效果顺序

  若数据层没有，本轮需要从 CE 目录补齐（怪物：`monsterCatalog`；武器：`weaponTable`）——**请核实补齐是否移动生成流**
  （数据字段新增本身不耗骰，但请证明）
- 虚弱：CE 用 `weaknessAmount` 影响**力量**而不是固定半伤——但 `weaknessAmount` 载体属于 U14（K14）。
  本轮若不能忠实实现，**明确登记为 U14 依赖**，不要自创替代公式；"隐形 ×1.5"同理先查 CE 出处
- W-21 强化、W-15 护盾、B-1 武器特性（突进/穿刺/偷袭倍数）都在同一公式链上：**只回归，不改它们的语义**
