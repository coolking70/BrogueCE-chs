## 2. 验收标准：**动作，不是图标**

W-0 原话"**等待、撞墙、不合法动作、攻击解除不能凭状态图标验收**"。
和 W-16 的"不凭飘字验收"同类——**必须断言被催眠者实际做了什么**：

- 玩家走一步，被催眠者**实际朝哪个方向动**了（"反向跟随"的具体语义请回 CE 查）
- 玩家**等待**时它做什么
- 它的移动方向**撞墙**时怎样
- 玩家做了**不合法的动作**（例如打开背包、说话）时它怎样
- 它**被攻击**时是否解除（"受击解除"），按 CE

**只断言"目标身上有 entranced 状态"不算通过。**
