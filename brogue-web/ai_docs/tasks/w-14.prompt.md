## 2. ⚠️ 两条容易走偏的约束

**① 新增 DF 目录项不能自动用于生成。**
往 `DungeonFeatureCatalog.ts` 补 `DF_FORCEFIELD` 行后，要确保**生成期不会因此用到它**
（否则就动了生成流）。`test:drift` 是判据。

**② 允许封路，且不得"堵路取消"。**
生成期的地形放置有连通性保护（不能切断通路）。但**玩家主动施放的阻障在 CE 里可以封路**
——W-0 原话"**允许封路**"、"**不得……堵路取消**"。
⇒ **不要为了保连通而让力场在会封路时自动取消**，那是把生成期的规则错套到交互期。

另一条：**不得硬编码固定面积**——扩散范围由 E 控制，按 CE 公式。

## 3. 硬约束
