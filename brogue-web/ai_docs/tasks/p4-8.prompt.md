# 任务 P4-8：气味图（scent map）

工作目录已是 `brogue-web/`。C 原版在 `../BrogueCE-master/src/brogue/`（唯一事实来源，**只读**）。

**授权反驳条款有效**：本任务书中的事实陈述可能有错，CE 源码优先；若我要求你实现 CE 里不存在的机制，请拒绝并在报告中指出。

## 病灶

CE 里怪物追踪玩家的主要手段是**气味**，不是直线视野。`MONSTER_TRACKING_SCENT` 状态的怪物顺着气味浓度梯度爬，所以它们会**绕过拐角、沿着你走过的路追上来**，而不是卡在墙后。

web 全仓没有 `scent` / `scentMap` / `scentTurnNumber` 的任何实现（我已 grep 确认）。怪物的追踪逻辑是简化的状态机（`src/entities/Monster.ts` 的 `MonsterState` 枚举：ASLEEP / WANDERING / HUNTING / FLEEING），靠可见性直接切 HUNTING。结果是怪物"看得见就追、看不见就傻站"，与 CE 的追踪手感差别很大。

## CE 事实（已逐条核实）

### 一、`scentDistance` —— Time.c:756-762

```c
short scentDistance(short x1, short y1, short x2, short y2) {
    if (abs(x1 - x2) > abs(y1 - y2)) {
        return 2 * abs(x1 - x2) + abs(y1 - y2);
    } else {
        return abs(x1 - x2) + 2 * abs(y1 - y2);
    }
}
```
注意这**不是**欧氏距离也不是切比雪夫距离：长轴权重 2、短轴权重 1。

### 二、`updateScent` —— Time.c:764-782

```c
static void updateScent() {
    char grid[DCOLS][DROWS];
    zeroOutGrid(grid);
    getFOVMask(grid, player.loc.x, player.loc.y, DCOLS * FP_FACTOR, T_OBSTRUCTS_SCENT, 0, false);
    for (i = 0; i < DCOLS; i++) for (j = 0; j < DROWS; j++) {
        if (grid[i][j]) addScentToCell(i, j, scentDistance(player.loc.x, player.loc.y, i, j));
    }
    addScentToCell(player.loc.x, player.loc.y, 0);
}
```
要点：
- 用 **`T_OBSTRUCTS_SCENT`** 做 FOV 遮挡（不是 `T_OBSTRUCTS_VISION`）——气味绕得过视线挡不住的东西，也会被某些挡不住视线的东西挡住。web 若无该地形标志，请用最接近的语义近似并在报告说明。
- 半径是 `DCOLS`（整张图）。
- 玩家所在格最后单独写 0。

### 三、`addScentToCell` —— Movement.c:2875-2882

```c
void addScentToCell(short x, short y, short distance) {
    if (!cellHasTerrainFlag({x,y}, T_OBSTRUCTS_SCENT)
        || !cellHasTerrainFlag({x,y}, T_OBSTRUCTS_PASSABILITY)) {
        value = rogue.scentTurnNumber - distance;
        scentMap[x][y] = max(value, (unsigned short)scentMap[x][y]);
    }
}
```
**注意那个条件是 `||` 不是 `&&`**——照抄，别"修正"成 `&&`。若你认为这是 CE 的笔误，可以在报告里指出，但**实现要照 CE**。

气味值是 `scentTurnNumber - distance`：**越新越大**，取 max 表示"保留最浓的那次"。

### 四、调用时机 —— Time.c:2610

`updateScent()` 在 `playerTurnEnded` 的**主观时间块**里，即**每玩家回合一次**（不是每 100 tick）。`rogue.scentTurnNumber` 同步递增。

### 五、跨层衰减 —— Time.c:2932-2933

```c
if (levels[d].scentMap[i][j] > 15000) {
    levels[d].scentMap[i][j] -= 15000;
}
```
这是防溢出的周期性回卷。web 若不做多层留存，可以不实现，但要在报告里说明。
