# 任务 P1-27：按决策 D2 移除自创的"深水淹死"

工作目录已是 `brogue-web/`。C 原版在 `../BrogueCE-master/src/brogue/`（唯一事实来源，**只读**）。

**授权反驳条款有效**：本任务书的事实陈述可能有错，CE 源码优先。

**前置**：这是 P1-24 的直接后续，先读 `ai_docs/p1_24_death_sink_report.md`——本轮要处理的正是它申报的第 1 和第 3 项。

## 背景：你上一轮的发现被验收方核实并采纳

你在 P1-24 报告里指出"CE 根本没有深水淹死机制"。验收方独立核实，结论一致：

```
Rogue.h:1932  T_LAVA_INSTA_DEATH = Fl(8)   // kills any non-levitating non-fire-immune creature instantly
Rogue.h:1937  T_IS_DEEP_WATER    = Fl(13)  // steals items 50% of the time and moves them around randomly
```
且全 CE 源码 `drown` 零匹配。**深水在 CE 只偷东西，不杀任何东西**；唯一的即死地形是熔岩。

所以 web 的"深水即死"是**自创内容**。按项目决策 **D2（自创内容保留在代码里，但不得出现在实际游戏中）**，本轮把它从实际游戏中移除。

这同时解决 P1-24 遗留的那条红测试：`scroll_effects.test.ts` 的召唤卷轴用例——seed 20260914 下有一只 Kobold 被召唤到玩家邻格的深水格，`die()` 修好后它真的死了。**不许改那条测试来迁就**；移除淹死后它应当自然转绿。若仍不绿，停下来报告。

## 必做

1. **玩家侧**：`Game.applyEnvironmentalEffects()` 的 `WATER_DEEP` 分支不再 `triggerGameOver`。
2. **怪物侧**：同分支不再致死。
3. 按 D2 的一贯做法：**代码保留、退出实际生效路径**，并在原处留注释说明"CE 无此机制、按 D2 退出游戏"，附上上面两行 CE 依据。参考 P1-21 处理其它自创内容的做法（`git log --grep=P1-21` 可查）。
4. **熔岩不动**：`T_LAVA_INSTA_DEATH` 是 CE 真实机制，且 CE 的豁免条件是"悬浮 或 火焰免疫"，请顺带核对 web 的熔岩分支豁免条件是否与 CE 一致，不一致就对齐，并在报告说明。

## 明确不做（写显式断言现状的测试留痕）

- **不要**实现 CE 深水的真实行为（50% 偷走物品并随机移位、`TM_ALLOWS_SUBMERGING` 潜水等）。那是独立的一轮，范围更大。本轮只做"不再致死"。
