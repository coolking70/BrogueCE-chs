# 任务 P4-7：玩家武器的攻击几何 + 钝器击退

工作目录已是 `brogue-web/`。C 原版在 `../BrogueCE-master/src/brogue/`（唯一事实来源，**只读**）。

**授权反驳条款有效**：本任务书中的事实陈述可能有错，CE 源码优先；若我要求你实现 CE 里不存在的机制，请拒绝并在报告中指出。

**前置**：上一轮 P4-6 已经实现了**怪物侧**的三种攻击几何，报告在 `ai_docs/p4_6_attack_geometry_report.md`。**务必先读它**——本轮是把同一套几何接到玩家身上，应当**复用** P4-6 建好的函数，而不是另写一套。若 P4-6 的实现不便复用，在报告里说明原因。

## 病灶

`src/data/weapons.json` 里 Whip / Spear / Axe / War Pike / Mace / War Hammer 的 `flags` 目前**全是空**。玩家捡到斧头砍一群怪，只能砍中一个；捡到长鞭，够不到远处。CE 里这些武器的说明文字（`weaponTable`，Globals.c:1582 起）明确承诺了这些行为，例如：

- whip：`"...it will reach opponents up to five spaces away."`
- spear / war pike：`"The reach of the spear permits you to simultaneously attack an adjacent enemy and the enemy directly behind it."`
- axe / war axe：`"The arc of its swing permits you to attack all adjacent enemies simultaneously."`
- mace / war hammer：`"...it takes an extra turn to recover when it hits, and will push your opponent backward if there is room."`

## ★ 旗标不在 weaponTable 里

**别去 `weaponTable` 找这些旗标——那里没有。** CE 是在生成物品时按武器种类赋予的，`Items.c:209-236`：

```c
switch (itemKind) {
    case DAGGER:              theItem->flags |= ITEM_SNEAK_ATTACK_BONUS;              break;
    case MACE:
    case HAMMER:              theItem->flags |= ITEM_ATTACKS_STAGGER;                 break;
    case WHIP:                theItem->flags |= ITEM_ATTACKS_EXTEND;                  break;
    case RAPIER:              theItem->flags |= (ITEM_ATTACKS_QUICKLY | ITEM_LUNGE_ATTACKS); break;
    case FLAIL:               theItem->flags |= ITEM_PASS_ATTACKS;                    break;
    case SPEAR:
    case PIKE:                theItem->flags |= ITEM_ATTACKS_PENETRATE;               break;
    case AXE:
    case WAR_AXE:             theItem->flags |= ITEM_ATTACKS_ALL_ADJACENT;            break;
}
```

旗标定义在 `Rogue.h:1376-1380`。

## 本轮范围

### 必做
1. **长鞭 `ITEM_ATTACKS_EXTEND`**：射程 5，`handleWhipAttacks`（Movement.c:855-912）。玩家分支：`if (!rogue.weapon || !(rogue.weapon->flags & ITEM_ATTACKS_EXTEND)) return false;`（Movement.c:869-871）。
2. **矛 / 战戟 `ITEM_ATTACKS_PENETRATE`**：直线穿透 2 格，`handleSpearAttacks`（Movement.c:917-1010）。玩家分支在 Movement.c:930-932。**注意攻击顺序是反的**（先远后近，Movement.c 里那句 `// Artificially reverse the order of the attacks` 的循环 `for (i = h-1; i >= 0; i--)`）。
3. **斧 / 战斧 `ITEM_ATTACKS_ALL_ADJACENT`**：横扫全部相邻，`buildHitList(..., sweep=true)`（Combat.c:2049-2092）。
4. **钉头锤 / 战锤 `ITEM_ATTACKS_STAGGER`**：
   - 命中后把目标推开一格 —— 复用 **P4-5 已实现的 `Game.processStaggerHit`**（Combat.c:1399 是玩家侧调用点）。
   - **外加**"多花一回合恢复"：`Time.c:2442` —— `if (rogue.weapon && (rogue.weapon->flags & ITEM_ATTACKS_STAGGER) && ...)`。请自行读该处确认具体口径再实现。

### 明确不做（写显式断言现状的测试留痕，不要静默跳过）
- 匕首 `ITEM_SNEAK_ATTACK_BONUS`（偷袭五倍伤害）
- 刺剑 `ITEM_ATTACKS_QUICKLY | ITEM_LUNGE_ATTACKS`（双倍攻速 + 突进）
- 连枷 `ITEM_PASS_ATTACKS`（移动时顺手攻击）
- CE 的 `abortAttack`（误伤盟友/酸怪的确认提示）——UI 交互
- Combat.c:760-772 把武器几何旗标复制给召唤出的镜像盟友——依赖召唤子系统
