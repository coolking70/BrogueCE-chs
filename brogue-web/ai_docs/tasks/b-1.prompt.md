## 病灶

P4-7 落地了鞭/矛/斧/钝器的几何与击退，但 CE 按武器种类赋予的旗标里**还有三个在 web 全仓零引用**：

```
ITEM_SNEAK_ATTACK_BONUS → 0 引用    匕首
ITEM_LUNGE_ATTACKS      → 0 引用    刺剑
ITEM_PASS_ATTACKS       → 0 引用    连枷
ITEM_ATTACKS_QUICKLY    → 0 引用    刺剑（与 LUNGE 同时赋予）
```

```c
case DAGGER: theItem->flags |= ITEM_SNEAK_ATTACK_BONUS; break;
case RAPIER: theItem->flags |= (ITEM_ATTACKS_QUICKLY | ITEM_LUNGE_ATTACKS); break;

```

`weapons.json` 里这三件武器的中文描述**早已向玩家承诺了这些行为**（与 P4-7 那轮同样的情形），请自己读一遍确认措辞，实现要与描述对得上。

## CE 事实（已逐条打开核实）

### 一、匕首：`ITEM_SNEAK_ATTACK_BONUS`（Combat.c:1259-1268）

```c
if (sneakAttack || defenderWasAsleep || defenderWasParalyzed || lungeAttack) {
    if (attacker == &player && rogue.weapon
        && (rogue.weapon->flags & ITEM_SNEAK_ATTACK_BONUS)) {
        damage *= 5;   // 匕首偷袭 5 倍
    } else {
        damage *= 3;   // 通用偷袭 3 倍
    }
}
```

**注意两点**：
1. **CE 本来就有通用 ×3**，匕首是把它升到 ×5，**不是从无到有**。
   web 目前有没有 ×3 基线？`Combat.ts` 里只有一个 `backstab` 布尔在传递，
   **请查清它到底有没有改变伤害**——若没有，本轮要把 ×3 一并补上，
   并在报告里说明这是补基线而非新增匕首特性。
2. 触发条件有四个：`sneakAttack`、`defenderWasAsleep`、`defenderWasParalyzed`、
   **`lungeAttack`**——刺剑突进也吃这个倍率。请确认 CE 里这四者各自的定义。

### 二、刺剑：`ITEM_ATTACKS_QUICKLY` + `ITEM_LUNGE_ATTACKS`

**攻速减半**（Time.c:2440-2449）：
```c
void playerRecoversFromAttacking(boolean anAttackHit) {
  if (player.ticksUntilTurn >= 0) {
    if (rogue.weapon && (rogue.weapon->flags & ITEM_ATTACKS_STAGGER) && anAttackHit) {
      player.ticksUntilTurn += 2 * player.attackSpeed;
    } else if (rogue.weapon && (rogue.weapon->flags & ITEM_ATTACKS_QUICKLY)) {
      player.ticksUntilTurn += player.attackSpeed / 2;
    } else {
      player.ticksUntilTurn += player.attackSpeed;
    }
  }
```
**分支优先级照抄**：STAGGER（且命中）> QUICKLY > 普通。
P4-7 已经在 web 的同名函数里落地了 STAGGER 那支，本轮在**同一处**加 QUICKLY 分支。

**突进**（Movement.c:1368-1391）：玩家朝某方向移动时，看**两格之外**
（`player.loc + 2 * nbDirs[direction]`）有没有敌人；有且满足
"看得见或已揭示 / 是敌人 / 非盟友 / 未在死亡中 / 不在阻挡通行的格内（除非
`MONST_ATTACKABLE_THRU_WALLS`）"，就把它列入 hitList。

请**自己读 Movement.c:1480-1500 附近**确认突进的完整语义——那里还有一处
`ITEM_LUNGE_ATTACKS` 的引用（1484），验收方没有展开读，**别只照我摘的这段实现**。

### 三、连枷：`ITEM_PASS_ATTACKS`（Movement.c:1392-1400 + buildFlailHitList，1025-1048）

```c
static void buildFlailHitList(const short x, const short y,
                              const short newX, const short newY,
                              const creature *hitList[16]) {
  for 每只怪 monst:
    if (distanceBetween({x, y}, monst->loc) == 1
        && distanceBetween({newX, newY}, monst->loc) == 1    // ★ 同时与移动前、移动后两格相邻
        && canSeeMonster(monst) && monstersAreEnemies(&player, monst)
        && monst->creatureState != MONSTER_ALLY
        && !(monst->bookkeepingFlags & MB_IS_DYING)
        && (!cellHasTerrainFlag(monst->loc, T_OBSTRUCTS_PASSABILITY)
            || (monst->info.flags & MONST_ATTACKABLE_THRU_WALLS))) {
        hitList[...] = monst;
    }
}
```

**核心判据是"同时与移动前和移动后两格都相邻"**——连枷是在两格之间挥过去的，
不是"移动时打所有相邻敌人"。这是最容易实现错的一点。
