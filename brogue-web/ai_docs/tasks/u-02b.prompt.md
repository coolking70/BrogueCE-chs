## 1. 本轮要做（按 U02a §6 编号，请逐条核实）

1. `raninit(uint64)`：c 异或高 32 位；web Random 在初始化边界接完整 uint64
2. `rand_64bits()`：同一流先 hi 后 lo 两次原始 ranval，计数只 +1
3. `initializeRogue` 的层种子表：`i=0…deepestLevel`，高位非零走 rand_64bits、否则走两次 `rand_range(0,9999)` 旧分支、
   0 改 i+1；**以及 CE 在同一循环里的其他消费**（U02a 指出有下梯坐标预抽等——请读清楚，能同构就同构，
   做不到的明确登记"逐骰不同构的位置"）
4. `startLevel` 新层分支：`oldSeed=rand_64bits()` 非零重试 → `seedRandomGenerator(levelSeed)` 同时重置两流 →
   本层生成全部消费层流（含 waypoint 构建——U02a 指出 web 现在 waypoint 自带隔离，要拆开）→ `seedRandomGenerator(oldSeed)` 回切
   → 之后的环境预热；**重访层不走这条支路**
5. `seedRandomGenerator` 不清 `randomNumbersGenerated`；计数归零只在新局/录像初始化——拆开两者
6. 层种子表、visited 标记进存档（当前层 schema；整局跨层 JSON 属 U03）
7. RNG 载荷算法标签升版本（U02a 已预留）

## 2. 生成流：大面积漂移的归因方法（必须）

漂移会同时来自多个杠杆，**必须分阶段独立归因**，每阶段单独记录再合并：
(a) 只改 raninit 高位 XOR（对 32 位种子应**零漂移**——这本身是一个检验）；
(b) 加层种子表初始化（改变第一层之前的消费）；
(c) 加每层 levelSeed 播种 + oldSeed 回切；
(d) waypoint 构建移入层流。
每阶段给出变化层数/字段数与"为什么这些变化只可能来自本阶段"的证明。全部完成后再**一次**重捕获基线。

## 3. 验收

- 同一种子：**交互（玩家在第 1 层做不同动作）不改变第 2 层及以后未生成层的地形**——这是层隔离的核心证明
- high=0 / high≠0 种子、生成出的 levelSeed=0 与 oldSeed=0 重试、首层/后层/重访
- U02a 的读档逐比特续跑守卫继续成立（存档含层种子表）
- 若能取得 CE 同种子第 1 层的某些可比量（例如楼梯位置），写出对照；做不到就写明
