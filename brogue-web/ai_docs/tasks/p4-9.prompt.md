## 病灶

web 的逃跑分支（`src/entities/Monster.ts:1042-1064`）是**贪心走向离玩家最远的邻格**：

```ts
const dist = Math.max(Math.abs(nx - game.player.loc.x), Math.abs(ny - game.player.loc.y));
if (dist > bestScore) { bestScore = dist; bestCell = { x: nx, y: ny }; }
```

只看切比雪夫直线距离、不看连通性。后果是**怪物会一头扎进死胡同**：只要死路方向的第一步比正确逃生路线离玩家更远，它就往里钻，然后被堵死在角落。CE 不是这么做的。

全仓也没有 `safetyMap` / `dijkstraScan` 的任何消费方（我已 grep 确认）。

## CE 事实（已逐条核实）

### 一、`updateSafetyMap()` —— Time.c:1791-1932

建两张代价图（`playerCostMap` / `monsterCostMap`），逐格填：

| 格子情形 | playerCost | monsterCost |
|---|---|---|
| 阻挡通行（且非未发现的密门） | `T_OBSTRUCTS_DIAGONAL_MOVEMENT` ? `PDS_OBSTRUCTION` : `PDS_FORBIDDEN` | 同左 |
| `T_SACRED` | 1 | `PDS_FORBIDDEN` |
| `T_LAVA_INSTA_DEATH` | 见下 | `PDS_FORBIDDEN` |
| 有怪物 | 5（分支内另有细分，**请自己读 Time.c:1830-1862 补全**） | 5 |
| 玩家看不见的密门 | 100 | 1 |
| 其余 | 1 | 1 |

熔岩那条 CE 原文是：
```c
if (player.status[STATUS_LEVITATING] || !player.status[STATUS_IMMUNE_TO_FIRE]) {
    playerCostMap[i][j] = 1;
} else {
    playerCostMap[i][j] = PDS_FORBIDDEN;
}
```
**这个条件读起来是反的**（按直觉应该是"免疫火焰 → 可走"）。**照抄，不要"修正"。** 如果你认为这是 CE 的笔误，可以在报告里指出，但实现照 CE——这是项目决策 D1。

然后：
```c
safetyMap[player.x][player.y] = 0;
playerCostMap[player.x][player.y] = 1;
monsterCostMap[player.x][player.y] = PDS_FORBIDDEN;
上楼梯、下楼梯格 → 两张图都 PDS_FORBIDDEN;

dijkstraScan(safetyMap, playerCostMap, false);

// 玩家看不见的密门：密门本身不安全，门后才安全
对这类格 resetDistanceCellInGrid(safetyMap, i, j);

// ★ 关键的数值变换
for 每格 (monsterCostMap >= 0):
    if (safetyMap == 30000) safetyMap = 150;
    safetyMap = 50 * safetyMap / (50 + safetyMap);   // 饱和压缩
    safetyMap *= -3;                                  // 取负 → 离玩家越远值越小
    if (IN_LOOP) safetyMap -= 10;                     // 环路更安全（有退路）

dijkstraScan(safetyMap, monsterCostMap, false);

for 每格: if (monsterCostMap < 0) safetyMap = 30000;
```

那个 `50 * v / (50 + v)` 是**饱和压缩**（远处差异被压扁），`*= -3` 把"离玩家的距离"翻成"安全度势场"，`IN_LOOP -= 10` 体现"有环路可绕的地方比死胡同安全"——**这三步正是它不会钻死胡同的原因**，别省。

### 二、`getSafetyMap(monst)` —— Monsters.c:2380-2400

```c
if (fleeingMonsterAwareOfPlayer(monst)) {
    释放怪物私有快照;
    if (!rogue.updatedSafetyMapThisTurn) updateSafetyMap();
    return safetyMap;              // 用全局实时图
} else {
    if (!monst->safetyMap) {
        if (!rogue.updatedSafetyMapThisTurn) updateSafetyMap();
        monst->safetyMap = allocGrid();
        copyGrid(monst->safetyMap, safetyMap);   // 只拍一次快照
    }
    return monst->safetyMap;       // 用自己那张旧快照
}
```
语义：**察觉不到玩家的逃跑者，按它最后知道的局面继续逃**，不会"隔墙感知"玩家新位置。这条别省，它是行为可信度的来源。

`fleeingMonsterAwareOfPlayer` 见 Monsters.c:2360-2378，请自己读。

`rogue.updatedSafetyMapThisTurn`（Time.c:1795 置位）—— **每回合最多重算一次**，不是每只怪都算。回合开始处清零，请自己找到对应位置。
