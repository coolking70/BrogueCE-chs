# U12a：一般怪物施法资格与目标选择

> **本地执行（Windows 轨）。X-0 路线；U12 的第一轮（第二轮 U12b = 盟友逃险/跟随/永久逃跑）。**

## 0. 规格以 X-0 勘察报告为准

**`ai_docs/reports/x-0-survey.report.md` 的 §4.1、§4.3 U12 行、§3.1 K10/K25 是权威规格**（`153dbb5`）：

> **U12 一般 AI/盟友战术**；K10/K25｜前置 U09/U18a｜生成流：间｜R: M、SafetyMap/Scent/Waypoint、G；
> S: teammates、enemies、boltEffect、moveAlly、fleeing、MODE_PERM_FLEEING、leader、reflection｜
> **拆为施法资格→盟友逃险/跟随两轮**；目标排序/掷骰位置同 CE，旧胜率非正确性标准

K10：一般施法/队友/反射敌人资格与 CE 不同；web 友方 bolt 只查 teammates，CE 还排 enemies；反射回避只散落在
NEGATION 等支路（Monster 约 :125–149、:1253–1289，对 CE Monsters.c 约 :2598–2631）。

## 1. 本轮范围（U12a）

- CE `monstUseMagic` / `monstUseBolt` / `generallyValidBoltTarget` / `specificallyValidBoltTarget` 的**通用部分**：
  施法者可见性/感知、目标遍历顺序（玩家优先？monsters 链顺序？）、`BF_TARGET_ALLIES/ENEMIES` 的完整阵营判定
  （`monstersAreTeammates` 且非 `monstersAreEnemies`）、反射目标回避（REFLECT_50/REFLECT_100 且非盟友时不射可反射 bolt）、
  forbiddenMonsterFlags、火系对火免/脚下可燃地形的回避、召唤（`summonMinions`）在施法链中的位置
- **U09 已补的各 bolt 专属门保留**（只回归）；本轮只收拢**通用门**，删除散落在各分支里的重复/矛盾判断
- `ALWAYS_USE_ABILITY || rand_percent(30)` 的掷骰位置与 CE 同构（资格失败不掷骰）
- 气体描边/潜水/献祭等 X-0 列出的"通用感知"差异：能忠实接的接，缺载体的（MB_SUBMERGED 等）登记

## 2. 验收

- 阵营矩阵：敌对/盟友/纷争/俘虏/被支配 × 友方 bolt/敌方 bolt，每格按 CE
- 反射回避、火免回避、脚下可燃回避正反例
- 目标遍历顺序与 RNG 调用序列（固定骰）与 CE 同构
- U07/U08/U09/U11 的所有施法测试只回归

## 3. 硬约束

- ❌ **不移动生成流**：`test:drift` 绿、不许重捕获
- ❌ 不做盟友逃险/跟随/永久逃跑（U12b）
- 📌 用户裁决：不做旧存档兼容；保留现状不是卡点

## 4. 教训

**验收方写的 CE 事实可能是错的，一律自行核实**（U22 刚发生过：任务书的"不泄漏"要求与 CE 不符——**发现任务书与 CE 冲突时，以 CE 为准并在报告里写明**）；
**撞上守卫时改代码，不改守卫、不绕扫描器**；**守卫靠旧规则才绿时**，先反事实证明，再只修前提、不动期望，交验收方裁决；
📌 **"胜率变了"不是回归判据——判据是与 CE 的规则/顺序一致**。
