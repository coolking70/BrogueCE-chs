## 1. 要找的是什么

**「挑 seed 的测试」= 选样 + 钉值**：测试先按 RNG 相关的条件**选出一个样本**
（"第一个有机器的层"、"第一个符合 X 的种子"、某个固定 seed 的某一层），
再**钉住那个样本的派生值**——而该值**并非在所有可选样本上都成立**。

生成流一动（任何加蓝图/改落位的轮次都会动），"第一个"就换了对象，于是：

| 败法 | 现象 | 危害 |
|---|---|---|
| **响的** | pin 撞红 | 看着像本轮引入了回归，白费一整轮的诊断力 |
| **哑的** | pin 退化成平凡真（`[]` / `∅` / 恒等） | **守卫停止守卫，没人发现** |

**哑的那种才是本轮的主要目标。**

### 已确认的样本（当模板用）

`p1_37_machine_flag_i18n.test.ts` 的 AD3：取**首个有机器的层**，钉住该层的
`A−B`（网格派生机器格集 − ∪mr.cells）。

- V-2b-3 查明：31 个有机器的层里 **25 层 A≠B**，且双向都差——
  断言的前提（"A−B 的每个格都必须是 item/monster 布点"）**从来就只在走运的那层成立**；
- V-2b-4 蓝图池一变，"首个"换了层，新层 `A−B = ∅` → **pin 顺延成 `[]`，该层的逐格循环
  自此空转**；
- 空转了**四轮**才被发现。

## 2. 主产物：风险清单

扫全部 **88 个**测试文件（`src/test/*.test.ts`），产出一份按风险排序的清单。

**验收方已先扫过一遍，把噪音口径告诉你，省得你重走弯路：**

- ❌ `grep "\.find("` —— 39 处命中，**绝大多数是良性的**（按名字找背包物品等确定性查找）；
- ❌ `grep "toBe(<数字>)"` —— 1047 处，毫无区分度；
- ✅ **真正的判据是「选样是否 RNG 相关」+「被钉的性质是否在全体可选样本上成立」**，
  这需要读代码判断，不是 grep 能定的。

每条给出：

| 字段 | 说明 |
|---|---|
| 文件:行 | 定位 |
| 选样方式 | 怎么挑出那个样本的（固定 seed？首个满足 X？） |
| 被钉的性质 | 钉了什么 |
| **风险等级** | **高**＝该性质在全体可选样本上不成立（已是或即将是假信心）／**中**＝成立但未验证／**低**＝选样与 RNG 无关 |
| **败法** | 生成流一动会**响**还是会**哑** |
| 建议修法 | 改成全体量化（对所有样本断言）／换不依赖 RNG 的选样／保留但加覆盖度守卫 |

**不要在本轮修它们** ——修法归后续轮，本轮只出清单。
