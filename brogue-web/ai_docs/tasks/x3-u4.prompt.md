## 0. 规格

**`ai_docs/reports/x-3-survey.report.md` 的 X3-B01、B02、B03、B04、B05、B07、C02、C03、E05（总表、§3、§4、§6、§8 的 X3-U4 行）是权威规格**，摘要：
- B01：引入 CE `rogue.disturbed` 语义——玩家受攻击（含未命中）、受伤、地形伤害/状态效果、发现秘密、以及**任何进入消息通道的消息**（呼应 CE `IO.c:3464` `message()` 置位）都打断旅行/探索；每个自动命令开始时清零。
- B02：探索遇相邻敌人按 CE `startFighting`（`Movement.c`）循环：`currentHP > expectedDamage`（easy 模式 /5）保命刹车、disturbed 打断、`blockCombatText` 期间战斗文字不打断；幻觉 `tillDeath` 语义按 CE。**用户试玩反馈即为此项**。
- B03：删"新物品即停"，只钥匙（及 B04 地形）打断；见怪打断排除盟友。
- B04：自动行进中首次看见 `TM_INTERRUPT_EXPLORATION_WHEN_SEEN` 地形（楼梯、传送门、锁门等）提示并打断。
- B05：Esc/空格（及任何非移动按键）停止自动探索/旅行。
- B07：自动行进期间抑制 CE 标注 "Don't interrupt exploration with this message" 的消息。
- C02/C03：见怪/见物消息按 CE 条件收窄（自动行进中、非盟友；物品只提示钥匙），删去自创 "You spot a X and stop …"。
- E05：可见集合更新与首见判定从渲染路径移入 `playerTurnEnded` 尾部（纯函数、零 RNG），保证 headless/回放与有渲染时停止点一致。
