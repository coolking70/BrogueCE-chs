## 1. 线索（**全部请自行核实**，读到执行路径）

- CE `BE_DAMAGE` 分支全文：免疫判定（火免对火系、`ignores` 消息）、`staffDamage(magnitude*FP_FACTOR)`、
  `inflictDamage` 的击杀分支、**反射杀死玩家的死因文案**、燃烧/点燃副作用、autoID 等——请读完整个 case
- 每种怪物 bolt 的 **CE magnitude**（boltCatalog 列）：spark、fire、dragonfire 各是多少；W-8 建的
  `staffDamage` 原语（E→伤害区间）直接复用，**不要另写一套**
- **BE_ATTACK ≠ BE_DAMAGE**（W-0 §2.6 原话）：`DISTANCE_ATTACK`、`POISON_DART`、`WHIP` 等是另一种效果，
  CE 里走的是攻击判定——**不能一起改**，要有测试证明它们保持原路径
- W-15 护盾吸伤、W-23 消魔、W-4 反射命中分派：法伤走新出口后这些交互是否一致
- 怪物施法时机/目标选择**不在本轮范围**（K10/U12）

## 2. 验收标准

- 三族法伤：伤害只由 magnitude 决定（黄金值：可编译 CE `staffDamage` 取分布边界），**不受施法者
  accuracy/damage、目标护甲影响**，不做命中判定
- 火免目标对火系免伤（及消息）；护盾先吸收；击杀走正常死亡链；反射命中施法者/玩家时的归因与文案
- BE_ATTACK 族行为**不变**（旧断言只回归）
- RNG：说明每次法伤消耗的随机调用数，与 CE 的 `randClumpedRange` 对齐
