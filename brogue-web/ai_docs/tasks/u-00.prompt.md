## 2. 验收标准（X-0 原话）

**"同实例 A 局 → B 局" 与 "新实例 B 局" 等价**：
- 在一个 Game 实例里先玩 A 局（造出统计、坠层队列、待处理请求、鉴定知识、跨层缓存、召唤/休眠状态、
  动画/输入锁等），再用 seed_B 开新局
- 与一个全新 Game 实例用 seed_B 开局比较：**完整状态 + 两条 RNG 流状态/计数** 应一致
- 三个入口都要验：**正常返回标题再开**、**死亡后重开**、**重放 restart/seek**

⚠️ "等价"要用**深比较**证明，不能只比几个字段。比较前需剔除的非确定字段（时间戳等）要列出理由。

**撞上守卫时改代码，不改守卫、不绕扫描器**；**注释写的是意图，执行路径里可能有例外**；
