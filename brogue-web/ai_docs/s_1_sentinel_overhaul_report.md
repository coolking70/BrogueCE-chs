**改造后共同性质**：同 seed 的断言结果只由「被测机制 + 固定合成场景 + 固定流起点」决定；

生成期的逐位流权威仍归 `generation_baseline` fixture（验收方随生成轮重锚，本轮未碰）。

**隔离场景的三件套**（c_5 对抗⑧ 当年只做了第 3 件，这次补齐并写进各哨兵注释）：
1. `createHeadlessGame(seed, 'test')`——`generateDepth` 走 `generateTestDepth` 合成层
   （Game.ts:720），**结构性绕开真实生成器**；

   （mode='test' 同时免周期刷怪，Game.ts:6173）；
3. 场景搭好后 `rng.seedRandomGenerator(K)` 显式重播种——流位置从固定点起算。

## 二、逐条说明：为什么选这个形态、改造后还能抓谁

### 2.1 f_2a 对抗⑪ / f_2b 对抗⑦（气体 14 回合全格曲线）
- **为什么是形态②而不是①**：守卫目的是"某轮顺手改了 updateGases/addGas/客观块次序"
  ——消耗量口径（①）抓不住"消散档位改了但掷骰数没变"这类错误；
  逐格曲线是最强口径，问题只出在场景锚定了流位置。把场景换成全隔离后，
  逐位曲线的全部牙都保留且对流位移免疫。
- **改造后还能抓**：updateGases 均分/消散/类型竞争被改（逐格体积变 → 红）；
  addGas 注入语义被改（t0 形态变 → 红）；客观块气体节奏被改（扩散速度变 → 红）；
  **气体路径新增任何掷骰**（流位移 → 舍入结果全变 → 红，§五实测）。
- **基线**：2026-09-17 S-1 实跑录制。POISON(34) 与 CONFUSION(35) 除 type 位外
  逐位相同（14 回合小注入下 SLOW/QUICK 尚未拉开可观测差距——档位差异的守卫
  仍由 g_1 对抗⑥ 的 QUICK>SLOW 损耗断言承担，20 回合 × 2000 体积口径，未动）；
  CREEPING_DEATH 恒空（D2 留痕，保留）。

### 2.2 f_2c 对抗⑪（中心/总量投影）
- 同 2.1 场景；投影基线重录为 center=[11,6,4,2,2]、total=[102,101,94,91,80]。
- **改造后还能抓**：同 2.1；总量序列额外抓"体积克隆/丢失"类回归。

### 2.3 f_2c 对抗⑩ / g_1 对抗⑧（火场 A，seed42）
- **为什么是②**：火哨兵的守卫目的是"本轮不许碰火"——蔓延概率/衰老掷骰/4 邻判据
  任何一处被改，曲线形态立变。原哨兵的缺陷不在逐位口径而在场景（真实地图 +
  `handlePlayerAction` 全回合）。合成火场 A（16×12 草块嵌密封地板房）下，
  40 回合覆盖"蔓延上升段 + 蔓延-衰老平衡段"，逐位牙完整保留。
- **改造后还能抓**：蔓延概率被改（上升段斜率变 → 红）；衰老被拆/加速
  （曲线持续上涨或提前塌陷 → 红）；点燃判据被改（首段形态变 → 红）；
  **火路径新增掷骰**（流位移 → 逐位红，§五实测）。

### 2.6 b_1a A13 → L1 + L2
- **为什么不是①或②**：物品生成签名是"地图 × 流"的复合产物。①消耗量口径在
  生成期必然地图相关（房间数决定发放次数）；②不存在"不经生成器的物品放置
  路径"（test 层不走 placeItems）。逐位流敏感性结构性不可救——按任务书
  "③只在前两种不适用时用"的次序，落③，并把守卫拆成两个可救的半边：
  - **L1 落格合法性**（全链 D1..D26 × seed 42/2026 每件生成物品）：
    CE 物品落位一律回避 `T_OBSTRUCTS_ITEMS | T_PATHING_BLOCKER`
    （Rogue.h:1926/:1948；web 的 floorTiles 牌堆与 P1-43 岩浆修复同源）。
    抓"牌堆判据被绕开/删除"（物品进墙/岩浆/深渊）。HEAD 上严格 0。
  - **L2 同种子双跑确定性**（seed42 全链跑两遍，逐层物品 FNV 签名逐位一致）：
    抓生成链里任何**非确定性**掷骰（Math.random 类泄漏——项目史上真实发生过的
    错误类，常识 §四）。与地形指纹测试"同一次运行内两次生成一致"口径对齐，
    对生成器改动免疫。
- **守卫降级登记**：对"新增抽取/改变池大小/调整发放顺序"的逐位流敏感性不再由
  本哨兵承担——那是 generation_baseline fixture 的职权。内容级错误由
  p1_20 / invented_content_pool / monster_damage_balance 等既有哨兵承担。

### 2.7 c_0 A4（判断项：选了"改锚定合成输入"）
- 原版把对照与写反变体跑在 HEAVY_SEEDS 的 52 个真实层上，门位数随流位移重抽，
  比值 2.978 vs 门槛 3 临界（C-6 实测翻红）。**重校倍数（如 ×2.5）只治标**：
  随机地图上的比值分布没有保证，下次改生成还会再临界的。
- 改造：合成工作网格（薄墙结构 = 真实地牢的形态）：
  - **华夫格**（5×5 小间、1 厚墙、墙段中点开口）：任意内墙两侧绕行距离
    < 20 → correct（>20 才开）一门不开、inverted（<20 即开）每墙必开
    ——蜂窝化的结构性形态（实测 190 门）；
  - **双走道**（1 厚墙夹两条走廊、右端竖连）：离连接口越远侧壁距离越远
    → correct 在远端开真环边门（实测 2 门）、inverted 只在近端开冗余门。
- 汇总常量化：correct=6、inverted=198、**比值 33×**；×3 门槛原样保留
  （任务书"阈值不许松"），余量从临界 2.978 变为结构性 33×。
- **有牙性论证**：把本测试的 open 判据写反（即 inverted 变体的定义），
  correct/inverted 互换，三道断言（常量、蜂窝数、比值）立即翻红。

### 2.8 c_5 对抗③（判断项：选了"扩样本"，并修正了原版错误的分布假设）
- **授权反驳（重要）**：原版注释声称"clump=2 的方差 ≈ 1/3"并把阈值设在 <0.5。
  实测 `randClumpedRange(8,10,2)`：numSides=⌊(10−8)/2⌋=1、remainder=0，
  两次 `randRange(0,1)` 各出 {0,1} → 分布 **{8:¼, 9:½, 10:¼}，方差恰为 0.5**。
  阈值正好压在正确实现的真值上——n=40 时 P(样本方差<0.5) ≈ 50%，这就是
  原哨兵掷硬币式翻红（C-6 样本 0.522）的根因，抽样运气既能让它红也能让它绿。
- 改造：**单局连坠**（层缓存 `levels` Map 按层号持久、恢复零生成掷骰，
  240 次坠落 ≈ 4s，比原版 40 次换种子重开两层还快）+ 分布带判据：
  - 支撑集 [8,10] 逐样本硬断言（min/max 写反 2d10/2d8 结构性翻红）；
  - 中值 9 频数 ∈ [99,141]（二项(240,½) 的 ±3σ，E=120）：
    clump=1 的 E=80（<0.1% 蒙混）、"恒定 9"平扣复辟 E=240、任何概率质量
    挪动 > ~8% 的改动都翻红；正确实现误红率 ≈ 0.3%（测试注释里写明）。
- **改造后还能抓**：坠落伤害的分布被改（支撑集/频数带）；坠落换层链断裂
  （每轮 depth 断言）。深水零伤/浅水减半半边保留原版逐种子形态（未动）。
